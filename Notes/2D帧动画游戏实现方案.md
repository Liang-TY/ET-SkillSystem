# 2D 帧动画游戏 — 基于帧同步包的实现方案

## 一、整体方案

基于 `cn.etetet.lockstep` 帧同步包直接修改，做一个最小测试 Demo：**按下 WASD 播放走路动画并移动，松开回到 Idle。**

### 核心决策

| 决策项 | 方案 | 原因 |
|--------|------|------|
| 逻辑帧率 | **30fps（33ms）** | 原包 20fps 动画太卡，30fps 是流畅度和性能的平衡点 |
| 动画帧持续时间 | **基础帧数（ticks）** | 天然和逻辑帧对齐，避免毫秒不对齐问题 |
| 播放速度控制 | **变速累积器（FP 定点数）** | 支持非整数倍速（如 1.7x），余数保留保证长期精度 |
| 动画精灵图 | **表现层** | 只影响视觉，逻辑层不关心图片资源 |
| 回滚 | **支持** | 利用原包的快照恢复机制，新增组件实现 ILSRollback |
| 实现阶段 | **直接改帧同步包** | 初期测试阶段，方便快速迭代 |

### 逻辑层 vs 表现层分工

```
逻辑层 (LSWorld, 30fps 确定性)           表���层 (Unity, 60fps+ 渲染)
─────────────────────────────            ──────────────────────────

LSInput (键盘输入)                       LSOperaComponent (采集 WASD)
  ↓                                        ↓
LSInputComponent.LSUpdate                 不关心
  → 根据 V 是否为零，播放 Walk 或 Idle
  → 移动 LSUnit.Position
  ↓
LSAnimComponent.LSUpdate                  LSSpriteAnimViewComponent.Update
  → FrameTick += Speed                    → 读 AnimId + FrameIndex
  → 超过 DurationTicks 时进下一帧          → 切换对应精灵图
```

**原则：逻辑层只管 AnimId + FrameIndex（第几帧），表现层根据这个索引显示对应的精灵图。**

## 三、实现步骤

### 第1步：修改逻辑帧率

修改 `Scripts/Model/Share/LSConstValue.cs`：

```csharp
public static class LSConstValue
{
    public const int MatchCount = 1;
    public const int UpdateInterval = 33;  // 30fps（原来 50 = 20fps）
    public const int FrameCountPerSecond = 1000 / UpdateInterval;
    public const int SaveLSWorldFrameCount = 60 * FrameCountPerSecond;
}
```

### 第2步：新增动画状态组件

新建 `Scripts/Model/Share/LSAnimComponent.cs`：

```csharp
using TrueSync;

namespace ET
{
    [ComponentOf(typeof(LSUnit))]
    [MemoryPackable]
    public partial class LSAnimComponent : LSEntity, ILSUpdate, IAwake, ISerializeToEntity
    {
        [MemoryPackOrder(0)]
        public int AnimId;           // 动画ID（0=None, 1=Idle, 2=Walk）

        [MemoryPackOrder(1)]
        public int FrameIndex;       // 当前帧序号

        [MemoryPackOrder(2)]
        public FP FrameTick;         // 定点数帧计数器（支持小数累积）

        [MemoryPackOrder(3)]
        public FP Speed;             // 播放速度倍率（1.0=正常）

        [MemoryPackOrder(4)]
        public bool IsLoop;          // 是否循环

        [MemoryPackOrder(5)]
        public bool IsFinished;      // 是否播放完毕（非循环动画用）
    }
}
```

**关键**：所有字段都是 `[MemoryPackOrder]` 标注的，确保快照序列化时能正确保存和恢复，回滚不会丢数据。

### 第3步：实现变速累积器系统

新建 `Scripts/Hotfix/Share/LSAnimComponentSystem.cs`：

```csharp
using TrueSync;

namespace ET
{
    [EntitySystemOf(typeof(LSAnimComponent))]
    [LSEntitySystemOf(typeof(LSAnimComponent))]
    public static partial class LSAnimComponentSystem
    {
        [EntitySystem]
        private static void Awake(this LSAnimComponent self)
        {
            self.Speed = FP.One;
        }

        [LSEntitySystem]
        private static void LSUpdate(this LSAnimComponent self)
        {
            if (self.AnimId == 0 || self.IsFinished)
                return;

            // ★ 变速累积器核心：每逻辑帧累加 Speed，而非固定 +1
            self.FrameTick += self.Speed;

            // 从配置读该帧的基础持续帧数
            AnimConfig config = AnimConfigCategory.Instance.Get(self.AnimId);
            FP duration = (FP)config.Frames[self.FrameIndex].DurationTicks;

            // 超过持续时间 → 进入下一帧，保留余数
            while (self.FrameTick >= duration)
            {
                self.FrameTick -= duration;  // 保留余数（关键！保证长期精度）
                self.FrameIndex++;

                if (self.FrameIndex >= config.Frames.Count)
                {
                    if (self.IsLoop)
                        self.FrameIndex = 0;
                    else
                    {
                        self.IsFinished = true;
                        return;
                    }
                }

                duration = (FP)config.Frames[self.FrameIndex].DurationTicks;
            }
        }

        // 播放动画
        public static void Play(this LSAnimComponent self, int animId, FP speed, bool loop = true)
        {
            if (self.AnimId == animId)
                return;

            self.AnimId = animId;
            self.FrameIndex = 0;
            self.FrameTick = FP.Zero;
            self.Speed = speed;
            self.IsLoop = loop;
            self.IsFinished = false;
        }
    }

    // 动画ID常量
    public static class AnimId
    {
        public const int None = 0;
        public const int Idle = 1;
        public const int Walk = 2;
    }
}
```

### 变速累积器的工作原理

以 Walk 动画 6 帧、每帧 DurationTicks=2、Speed=1.7 为例：

```
逻辑帧:    1      2      3      4      5      6      7      8
每帧+1.7   +1.7   +1.7   +1.7   +1.7   +1.7   +1.7   +1.7   +1.7

动画帧0(DurationTicks=2):
  tick:    0→1.7  1.7→3.4
  3.4>=2 → 进帧1, 余数=1.4
  显示:   [帧0    ]（2个逻辑帧）

动画帧1(DurationTicks=2):
  tick:    1.4→3.1
  3.1>=2 → 进帧2, 余数=1.1
  显示:           [帧1]（1个逻辑帧）

动画帧2(DurationTicks=2):
  tick:    1.1→2.8
  2.8>=2 → 进帧3, 余数=0.8
  显示:                [帧2]（1个逻辑帧）
  ...
```

每帧持续时间不完全一样（1帧或2帧），但**平均精确等于 2/1.7 ≈ 1.18 个逻辑帧**，长期无误差。

### 第4步：重写 LSInputComponentSystem

替换 `Scripts/Hotfix/Share/LSInputComponentSystem.cs`：

```csharp
using TrueSync;

namespace ET
{
    [EntitySystemOf(typeof(LSInputComponent))]
    [LSEntitySystemOf(typeof(LSInputComponent))]
    public static partial class LSInputComponentSystem
    {
        [EntitySystem]
        private static void Awake(this LSInputComponent self) { }

        [LSEntitySystem]
        private static void LSUpdate(this LSInputComponent self)
        {
            LSUnit unit = self.GetParent<LSUnit>();
            LSAnimComponent animComp = unit.GetComponent<LSAnimComponent>();

            TSVector2 v2 = self.LSInput.V * 6 * LSConstValue.UpdateInterval / 1000;

            if (v2.LengthSquared() < 0.0001f)
            {
                // 没有移动输入 → 播放 Idle
                if (animComp.AnimId != AnimId.Idle)
                {
                    animComp.Play(AnimId.Idle, FP.One, loop: true);
                }
                return;
            }

            // 有移动输入 → 移动 + 播放 Walk
            TSVector oldPos = unit.Position;
            unit.Position += new TSVector(v2.x, 0, v2.y);
            unit.Forward = unit.Position - oldPos;

            if (animComp.AnimId != AnimId.Walk)
            {
                animComp.Play(AnimId.Walk, FP.One, loop: true);
            }
        }
    }
}
```

### 第7步：实现精灵动画视图系统

新建 `Scripts/HotfixView/Client/LSSpriteAnimViewComponentSystem.cs`：

```csharp
using UnityEngine;

namespace ET.Client
{
    [EntitySystemOf(typeof(LSSpriteAnimViewComponent))]
    public static partial class LSSpriteAnimViewComponentSystem
    {
        [EntitySystem]
        private static void Awake(this LSSpriteAnimViewComponent self) { }

        [EntitySystem]
        private static void Update(this LSSpriteAnimViewComponent self)
        {
            LSUnit unit = self.GetParent<LSUnitView>().GetUnit();
            LSAnimComponent animComp = unit.GetComponent<LSAnimComponent>();

            // 动画ID变了 → 加载新的精灵图数组
            if (animComp.AnimId != self.LastAnimId)
            {
                // TODO: 根据AnimId加载对应精灵图，暂时用占位
                // AnimConfig config = AnimConfigCategory.Instance.Get(animComp.AnimId);
                // self.CurrentSprites = Resources.LoadAll<Sprite>(config.SpritePath);
                self.LastAnimId = animComp.AnimId;
            }

            // 帧索引变了 → 切换精灵图
            if (animComp.FrameIndex != self.LastFrameIndex)
            {
                if (self.CurrentSprites != null && animComp.FrameIndex < self.CurrentSprites.Length)
                {
                    self.SpriteRenderer.sprite = self.CurrentSprites[animComp.FrameIndex];
                }
                self.LastFrameIndex = animComp.FrameIndex;
            }
        }

        // 回滚时同步视觉
        [EntitySystem]
        private static void LSRollback(this LSSpriteAnimViewComponent self)
        {
            LSUnit unit = self.GetParent<LSUnitView>().GetUnit();
            LSAnimComponent animComp = unit.GetComponent<LSAnimComponent>();

            // 动画可能回退（比如之前预测Walk，回滚后发现还是Idle）
            if (animComp.AnimId != self.LastAnimId)
            {
                // 重新加载精灵图
                self.LastAnimId = animComp.AnimId;
            }

            // 帧索引也可能回退
            if (self.CurrentSprites != null && animComp.FrameIndex < self.CurrentSprites.Length)
            {
                self.SpriteRenderer.sprite = self.CurrentSprites[animComp.FrameIndex];
            }
            self.LastFrameIndex = animComp.FrameIndex;
        }
    }
}
```

## 四、如何修改和测试

### 开发环境搭建

1. 用 Unity 打开项目，确保帧同步包 `cn.etetet.lockstep` 已正确引入
2. 按照 `Book/1.1运行指南.md` 跑通原始 Demo（确认基础环境正常）
3. 在此基础上开始修改

### 修改代码的流程

```
1. 修改源码
   ↓
2. Unity 中按 F6 编译（或在 IDE 中编译）
   ↓
3. 运行服务端（Unity Menu → ServerTools → Start Server）
   ↓
4. 运行客户端（Play）
   ↓
5. 测试功能
   ↓
6. 如需热重载：按 F7（服务端）/ F6+F7（客户端）
```

### 测试1：确认 30fps 帧率生效

1. 只改 `LSConstValue.UpdateInterval = 33`
2. 运行服务端 + 客户端
3. 观察日志中 `OneFrameInputs` 的打印频率是否变为约 30 次/秒
4. 角色移动应该比原来更流畅

### 测试2：确认动画组件正常序列化

1. 按第2-5步添加 LSAnimComponent 并挂载
2. 运行游戏进入战斗
3. 开启 ENABLE_CODES 宏，在 Unity Hierarchy 中查看 LSWorld 下是否有 LSAnimComponent
4. 检查 hash 校验日志，确认无 CheckHashFail 报错
5. 如果出现 CheckHashFail → 说明序列化有问题，检查 MemoryPackOrder 是否连续

### 测试3：确认动画帧推进正确

先不接配置表，硬编码测试：

```csharp
// 临时硬编码在 LSAnimComponentSystem.LSUpdate 中，替代配置表读取
[LSEntitySystem]
private static void LSUpdate(this LSAnimComponent self)
{
    if (self.AnimId == 0 || self.IsFinished)
        return;

    self.FrameTick += self.Speed;

    // 硬编码：Idle 2帧循环，Walk 6帧循环，每帧持续 1 个逻辑帧
    int totalFrames = self.AnimId == AnimId.Walk ? 6 : 2;
    FP duration = FP.One;  // 每帧 1 tick

    while (self.FrameTick >= duration)
    {
        self.FrameTick -= duration;
        self.FrameIndex++;

        if (self.FrameIndex >= totalFrames)
        {
            if (self.IsLoop)
                self.FrameIndex = 0;
            else
            {
                self.IsFinished = true;
                return;
            }
        }
    }

    Log.Debug($"Anim:{self.AnimId} Frame:{self.FrameIndex} Tick:{self.FrameTick}");
}
```

运行后观察日志输出：
- 按 WASD → AnimId 变为 2（Walk），FrameIndex 在 0-5 循环
- 松开 → AnimId 变为 1（Idle），FrameIndex 在 0-1 循环

### 测试5：确认回滚不影响动画

1. 运行两个客户端实例（或模拟网络抖动）
2. 观察回滚日志：`roll back start` / `roll back finish`
3. 确认回滚后动画状态恢复正常（不会卡在错误的动画或帧上）
4. 如果回滚后动画异常 → 检查 LSSpriteAnimViewComponent.LSRollback 是否正确读取了逻辑层状态

### 注意事项

1. **每次改完 Model 层要重新编译**：新增组件后必须 F6 编译才能生效
2. **先确认原包能跑**：在改任何代码之前，先确保原版帧同步 Demo 能正常运行
3. **新增组件必须是 MemoryPackable**：否则快照序列化时无法保存，回滚会丢数据
4. **LSWorld 的子实体必须用 LSEntity 基类**：不能用普通 Entity，否则不被 LSWorld 管理
5. **逐步测试**：先改帧率确认能跑 → 再加组件确认序列化 → 再加动画系统 → 最后加精灵图，不要一次全改
