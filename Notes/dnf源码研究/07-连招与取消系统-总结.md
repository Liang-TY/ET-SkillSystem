# 第三轮总结①：DNF 连招与取消系统（指令输入/普攻连段/取消层级）

> 课题：Q9——指令输入（↓→+Z）、普攻连段、取消/柔化的完整机制。
> 来源：.skl [command] 语法全库统计（273 个含指令技能）+ CNRDCommandChecker 声明 + 男鬼剑 attack.nut 实读 + cancelskilllist.co 全表 + 柔化 appendage 源码。
> 用途：验证/修订我们 04b 打击感的 cancelFlag/输入缓冲设计。**只列建议，改不改用户定。**

## 1. DNF 怎么做的

### 1.1 指令输入系统（.skl [command] + CNRDCommandChecker）

**语法**：`{槽位=记号}` 序列，两种连接符：

| 记号 | 含义 | 连接符 | 含义 |
|------|------|--------|------|
| `(UP)(DOWN)(LEFT)(RIGHT)` | 方向键 | `{8=`,`}` | **顺序**：前一键松开后再按下一键（先后） |
| `(SKILL)` | Z 技能键 | `{8=&}` | **同按**：按后一键瞬间前一键仍按住（按住/同时） |
| `(ATTACK)` | X 攻击键 | | |
| `(JUMP)` | C 跳跃键 | 二进制层：`[@05]`=指令段头、`[@06]`=键记号、`[@08]`=连接符 | |
| `(BUFF)` | Space | | |

**硬规律**（273 技能全库统计）：指令长度 1~5 键；**收尾键永远是动作键**（SKILL 445 次/BUFF 141/JUMP 27/ATTACK 25），方向键只做前缀；`&` 只用于"方向键&动作键"两键组合（35 处）；三套编号并存（rdarkeyindex 数据键号 / E_COMMAND 检查器命令号 / OPTION_HOTKEY 键位设置号）。

**实例**：上挑=Z；三段斩=→按住+Z；后跳=↓按住+C；十字斩=←,→,Z；崩山击=→,↓,Z；邪神怖拉修=↑,↑,↓,↓,Z；银光落刃=Z（但状态条件是"跳跃中"——条件不在指令里）。

**匹配机制**：每个候选序列**独立记录进度**，收到不匹配预期的键即重置该序列、完成即触发（十字斩←→+Z 与破军←→→+Z 并存实证）；`&` 要求按后一键时前一键仍按住。**超时窗口数值无公开信源（缺口）；前缀重叠的精确仲裁规则无源码（缺口）**。CNRDCommandChecker 公开 API 仅 2 个（`setAIMode`/`commandListReset`）——脚本常规姿势是**轮询 `sq_IsEnterSkill(id)`** 等引擎通知。

**手搓增益**：`[skill command advantage]` = 指令施放（手搓）时**冷却减少‰、MP 消耗减少‰**（爆头 10/20=CD-1%/MP-2%）；快捷键施放吃不到——这是"为什么要做指令输入"的数值动机。

### 1.2 普攻连段（引擎原生推进 + 脚本回调例外）

- **架构**：普攻 X 键走引擎原生 `STATE_ATTACK=8`（非技能）。attack.nut 里**没有连段推进代码**——引擎按 `getAttackCancelStartFrame(N)` 表推进 0→1→2，脚本只通过回调注入例外：
  - `getAttackAni_*(obj,index)` 每段动画 / `getDefaultAttackAttackInfo_*` 每段攻击信息 / `getAttackCancelStartFrame(Size)_*` 连段窗口与段数（短剑精通可改 3 段）
- **连段窗口 = [cancelStartFrame 时刻, 本段动画播完]**，无独立连段计时器。第 N 段动画帧 ≥ cancelStartFrame(N) 且 X 重按 → 下一段；超时不按 → 回站立，**下一击从第一击重来**。
- **每段 .atk 反应差异 = 连招手感的数据层**：attack1 推走(lift 75)、attack2 推走(lift 90)、**attack3 击飞(DOWN+lift 300)**——收尾段浮空值是连招起手感的来源。
- 移动普攻=同状态 8 + `sq_StopMove` 截停；前冲攻击=STATE_DASH_ATTACK(15)（+40% 伤害/push 50）；跳攻=7；方向变体全走指令系统（↓+X=蹲攻 20、↓+C=后跳 169、后跳中 X=后跳斩 49）。
- **攻速对全部生效**，动画按速度缩放，连段窗口随之压缩。

### 1.3 取消系统四层级（从松到紧）

```
① 柔化（任意技能帧可取消，黑名单外全状态）
② 普攻取消进白名单技能（普攻中后段，引擎按 cancelskilllist.co 控制）
③ 普攻段间推进（cancelStartFrame 后重按 X）
④ 动画自然结束
```

- **cancelskilllist.co**（客户端白名单）：`[cancel skill]` 按职业+转职列技能 ID。规律：**通用层=低级小技能+后跳；转职层=本系核心输出技**（如红眼+崩山击、阿修罗+三波动剑）。
- **柔化（女格斗被动 171）**：常驻 appendage 的 `proc` **每帧轮询**——`EnableSoften`（点亮技能）+ `SetSkillState`（`sq_IsEnterSkill` 检测 → `sq_IsUseSkill` 校验扣费 → `sq_AddSetStatePacket` 顶掉当前状态）。约 30 行三件套，任何职业可抄。**状态黑名单**：站立（本来就能放）/受伤/倒地/死亡/抓取/拾取——被控状态不该被取消。男鬼剑 MOD"体术逆改"(252) 同款。
- `setEnableCancelSkill_*` 由**引擎**在取消窗口开/关时调用，脚本借机点亮白名单外的新技能。
- **后摇取消不等动画结束**：柔化在任意帧直接 USER 优先级顶掉当前状态；USER < FORCE/IGNORE_FORCE，所以被击/抓取仍能打断你的取消。

### 1.4 输入缓冲的真相

- **DNF 没有现代预输入缓冲**：`sq_IsEnterCommand` 当帧判定（`sq_SetKeyxEnable` 先使能再查 = "这一帧才监听"），**按早（未到 cancelFrame）或按晚（动画结束）都丢弃**。柔化/流心的"每帧 proc 轮询"等价于全动画缓冲。
- **时间量级**：普攻每段 0.5-0.65s；取消窗口从动画中段（~250ms）开到段末；受击方硬直恢复 600ms（.chr [hit recovery]）。
- **顿帧定位**：攻方普攻**不停帧**——打击感靠受击方僵直 + 每帧判定盒 + 攻速节奏；`hitStunTimeAttackerDamager` 是同时冻结攻受双方的僵直字段（最接近 hitstop 的机制）。

## 3. 建议改动清单

1. **`04b`：连段窗口语义修正**——DNF 的窗口是 **[cancelFrame 时刻, 本段动画播完]**（动画剩余时长），不是固定 300ms。我们的 InputBuffer 保留（更友好），但**消费条件对齐**：只在"当前动画帧 ≥ cancelFlag 帧"后才允许消费缓冲（对齐 DNF 的"按早丢弃"，但我们缓冲保留——折中：缓冲到 cancelFlag 后才生效）。
2. **`04b`/attack.json：普攻连段数据结构**——每段配 ①下一段开放帧（cancelStartFrame 等价物=每段的 cancelFlag）②段级受击反应参数（**末段击飞 DOWN+upForce=300，前段推走 lift 75~90**——直接抄 DNF 数值比例）。
3. **`04b`：顿帧定位确认**——攻方普攻不停帧；打击感=受击僵直+每帧判定盒+攻速节奏。我们的 HitstopTimer（双方冻结）对应 `hitStunTimeAttackerDamager`，设计同构，保留。
4. **`05-阶段4`：加"普攻可取消技能白名单"**（cancelskilllist 等价物，职业配置一份列表）；柔化=远期（常驻 buff + 每帧轮询取消，DNF 三件套 30 行可平移到 LSBuffComponent）。
5. 指令输入（→+Z）后置备忘：做的时候语法用 DNF 这套（方向前缀+动作键收尾+&/, 两连接符），匹配器=每序列独立进度+错键重置；手搓增益可选加。
6. `04b` 输入缓冲注明与 DNF 的差异：我们缓冲 300ms（现代手感），DNF 当帧判定——两者都确定（帧同步下缓冲内容按逻辑帧采样）。
