### 原帖补充（PDF 转录里没有/不清楚的，已并入 02 篇）

**目标点怎么选（两条规则）：**
1. X 轴一般为**视觉中心线**——整个图像的中心线或人物的中心线 → 第一个 X 坐标就出来了。
2. Y 轴一般是变动的，不同东西不一样，因为要**对齐的游戏人物基础轴线**不同，没法统一计算。

**各类型锚点细则：**
- 光环·主体部分：视觉中心，与角色的中心点对齐。
- 光环·脚底部分/天空脚印之类：NPK 右上角到动画中心点即可。
- 宠物：a) 普通地面型=NPK 右上角到宠物中心点；b) 浮空型（兔精灵战士灵芸）中心点下移保持悬浮；c) 人物型=身体中心点，按浮空/奔跑状态调 Y。

**[IMAGE RATE] 完整语义（两参数=两轴）：**
```
1.0  1.0   不变
0.5  0.5   缩小到 50%      1.5 = 150%      2 2 = 放大两倍
-1   0.8   水平翻转 + 纵向缩 0.8    ← 第一个数管 x（负=水平翻转）
 1  -0.8   垂直翻转                  ← 第二个数管 y（负=垂直翻转）
```
人物贴图转向可用此词条；NPC 左右朝向一般由地图调用的 `Left` 词条控制（两条路）。

**[GRAPHIC EFFECT] `LINEARDODGE` = 线性减淡（去黑底）**：带黑底的贴图必须每帧加，否则游戏里显示黑底框。

**其他**：[FRAME MAX] = img 最大帧数+1；词条讲解出处 PVF 吧扒号技师。

## 2. Musoucrow《DNFMobile 图片资源提取笔记》

- URL：https://musoucrow.github.io/2018/01/20/dnf_mobile_ex/
- 可信度：**一手技术实证（DNF 手游资源逆向）**

关键摘录：
- DNFMobile 是 Unity 制作，图集运行时由脚本生成 Sprite（不是 Unity 预生成）。
- **"Unity 的 Sprite 的 pivot 与 DNF 的 IMG 包提供的偏移点可谓天南地北（一者为当前图片下的浮点百分比，另一者为实际坐标）"** → 官方手游的解法与我们一致：offset 留在配置里（他们存 json 的 offsetX/offsetY），运行时转换，而不是烤进图集。
- 其 DNFAtlasElement 结构：`{ name, originIndex, referenceIndex, originWidth, originHeight, offsetX, offsetY, rect }` —— 与端游 img 字段一一对应（含引用帧 referenceIndex）。
- 纸娃娃（换装）用类似 NPK v4 的色板做法。
