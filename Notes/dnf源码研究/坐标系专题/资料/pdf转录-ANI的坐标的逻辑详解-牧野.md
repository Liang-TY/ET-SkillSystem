## 页 0：开篇与核心结论

- 作者：牧野（QQ 1320113373），写自 DNF modding 社区。
- 痛点：自制光环/称号等时装素材时，ani 文件坐标不知怎么算。
- 前人给过的**粗略公式**（用 img 的信息：img 坐标 [X1,Y1]，宽高 [X2,Y2]）：
  - `X = -X1 - X2/2`
  - `Y = -Y1 - Y2/2 - 60`
  - 评价："只是一个粗略的坐标，具体在游戏里调整也是一个头疼的问题"。
- **牧野的结论（先说结论）**："ani 坐标比想象中简单的多，只需要勾选**真实坐标、显示出边框**，选个目标点，**从画布左上角到目标点截图，尺寸取负，这个就是 ani 的坐标**。"
- 配图：ani 编辑器截图——角色贴图（138×182，蓝色选框+控制点），绿色箭头标注"选个点，截图"；右侧属性面板 `[IMAGE POS] -138 -183`，`[DELAY] 120`。"这样一看就一目了然了"。
- 印证：138 宽的图，锚点在贴图水平中点 → X = -(138/2 + 0) = -138/2… 实例值 -138 -183 与"画布左上→目标点取负"直接对应。

## 页 1：分析 `[直读，未双验证]`

- 对粗略公式的分析：X1+X2/2、Y1+Y2/2 即求图片中心在画布中的位置，取负后即"锚点在图片中心"；-60 是"中心锚"到"脚底锚"的经验修正量——所以只是粗略。
- 编辑器实操演示：勾选"真实坐标/显示出边框"后，编辑器会把帧域（画布）边框画出来，直接量画布左上角到目标点（如脚底中心）的距离即可，不用背公式。

## 页 2：不同内容的锚点语义 + ANI 词条结构

- **锚点（目标点）按内容类型不同**：
  - **宠物：视觉中心**，分几种情况：
    - a) 普通（地面跑的）：画布左上角到宠物中心点
    - b) 浮空（如兔精灵战士灵芸）：飘着的，中心点要下移，保证游戏内也是漂浮状态
    - c) 人物类：一般为人物身体中心点，根据浮空/奔跑状态做 Y 轴上下调整
  - **称号：最简单 (0,0)**——只用 IMG 坐标 (0,0)，图片尺寸与帧域尺寸一致。
- **ANI 文件基本结构**：
  ```
  [LOOP] 1                    // 循环；只需显示一次可不写（比如技能特效等）
  [FRAME MAX] 2               // 帧数：这个 ANI 总共有多少帧内容
  [FRAME000]                  // 帧编号，从 0 开始
  [IMAGE]
  `Map/Npc/Npc_se.img`        // 调用 NPK 里图片的路径
  0                           // img 里的图片编号（帧号）
  ```

## 页 3：IMAGE POS 实例与 IMAGE RATE

```
[IMAGE POS]
-51 -162        // 图片显示位置坐标 X Y 坐标
[DELAY]
180             // 显示一帧的停留时间，1000 为一秒

[FRAME001]      // 第二帧
[IMAGE]
`Map/Npc/Npc_se.img`
1
[IMAGE POS]
-51 -162
[DELAY]
180
```
- **[IMAGE RATE] 缩放词条**（做特效经常用）：
  - `-1.0 1.0` —— 不只可以改贴图显示大小，还可以**翻转**等操作（x 取负 = 水平翻转）
  - `0.5 0.5` —— 缩小一倍；放大类似写法

## 页 4：RGBA 词条说明 `[直读，未双验证]`

- 引出 `[RGBA]` 词条：按 R G B A（0-255）改颜色/透明度，A=255 不透明，A 越小越透明。

## 页 5：RGBA 闪烁用法与 INTERPOLATION

- "当最后一个参数写 0，这一帧图片就完全透明了。通过这个词条可以在第一帧写 229、第二帧 204 逐步递减到 50 左右，然后再逐步递增到 229——这样一个循环就得到了一个**闪烁的 ANI**。"
- 变色操作作者未测试过，不知可不可以。
- **[INTERPOLATION] 1**：经常搭配 [RGBA]（透明度 <255 时使用），作用是让图像**抗锯齿**。
