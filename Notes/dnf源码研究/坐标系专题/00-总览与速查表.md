## 速查表（打印级）

### 坐标/尺寸量一览

| 量 | 所在 | 原点/基准 | 轴向/单位 | 一句话 |
|---|---|---|---|---|
| 位图 W×H | IMG 帧 | — | px | 紧致裁剪后的真实内容块 |
| X / Y | IMG 帧 | 帧域画布左上角 | px，y 下正 | 位图贴在画布哪里 |
| FrameW×FrameH | IMG 帧 | — | px | 画布规格（角色 500×500，特效可 205×128） |
| [IMAGE POS] | ANI 帧 | **锚点**（角色=脚底中心） | px，x 右正 y 下正 | 帧域左上角相对锚点 |
| 位图左上角 | 推导 | 锚点 | px | **= IMAGE POS + (X,Y)** |
| [DAMAGE/ATTACK BOX] | ANI 帧 | 锚点 | px | 6 值 min(x,y,z)+max；x横向/y纵深/z高度上正 |
| 世界坐标 | 引擎/NUT | 房间/场景 | px（我们÷100） | x横向 / y纵深 / z高度（跳跃轴） |
| Unity 单位 | 我们引擎 | — | 1单位=100px | PPU=100；TSVector(x←x, y←z, z←y) |

### 核心公式

```
摆位：   位图左上角(锚点空间) = [IMAGE POS] + (X, Y)            // y 下正
验证：   posY + Y + 位图高 ≈ 0                                  // 角色底边贴脚
盒镜像： 面左 → x 区间 [min,max] → [-max,-min]，y/z 不变
Unity：  renderer.local = ((posX+X+w/2)/100, -(posY+Y+h/2)/100) − prefab中间层偏移
        （内容中心版；等价摆法见 05 篇）
盒采样： worldMin = pos + (minX/100, minZ/100, minY/100)（面左先镜像 x）
```

### 锚点语义

| 资源 | 锚点 |
|---|---|
| 角色/怪物 | 脚底中心 |
| 特效/投掷物 | 视觉中心/生成点 |
| 称号 | (0,0)，位图=帧域 |
| 浮空宠物 | 视觉中心下移（保持悬浮感） |

### 十条铁律

1. IMAGE POS 的大负数是抵消画布偏移，不是精灵尺寸。
2. imagePos 逐帧独立配（kneekick 动作内跳变 81px），禁止整段动画共用偏移。
3. 盒的 y 是纵深、z 才是高度；和 IMAGE POS 的屏幕 y 是两套。
4. 盒是手配 frame data，不是自动剪影；源数据要归一化 min/max。
5. 攻击盒只在判定帧出现，一帧可多盒（kneekick 帧双盒实测）。
6. 帧域尺寸随资源不同；运行时定位不需要 FrameW/H，裁剪打包时必须要 X/Y。
7. 特效位置 = 生成点（挂点）+ 特效自身摆位，两跳都要查。
8. 面左 = 位置 x 取负 + 贴图绕锚点翻转，两件事一起做（只翻贴图差 2×偏移x）。
9. 引用帧无自身坐标元数据，取被引帧的；同图不同摆位用 .ani 不同帧配不同 IMAGE POS 解决。
10. 像素:单位 = 100:1（贴图与判定像素 1:1，不再缩放）。
11. 判定盒两种来源：近战=动作 .ani 的 ATTACK BOX（帧驱动）；投射物/特效=nut 挂的 attackInfo 配置（动画只管表现）。详见 04 篇。
