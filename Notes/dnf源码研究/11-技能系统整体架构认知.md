# DNF 技能系统整体架构：一篇看懂

> 承接 09（动画架构）、10（特效架构）。本篇把三轮研究（01/04/05/07 号文档）拼成技能系统的总图。
> 目标：读完知道"技能是什么、一次施放从头到尾经过什么、技能的四种形态、连招取消怎么叠在上面"。

---

## 0. 一句话总纲

**DNF 的一个技能 = 状态机的一个状态 + 一份 .skl 数值表 + 一段 .nut 脚本。**

- 技能不是独立对象——它是**角色状态机的一个状态**（`pushState(职业, 脚本路径, 状态名, 状态ID, 技能ID)` 注册；状态 ID 和技能 ID 是两套编号）。
- 释放技能 = **切状态**（`sq_AddSetStatePacket`，走网络包，全端同步）。
- 状态里播动画、出判定、造特效——动画帧数据是节拍器（见 09）。
- 脚本无状态（纯函数集，引擎按函数名回调），运行时状态挂在角色对象上（状态号/子状态/getVar 槽/动画帧号）。

## 1. 一次技能施放的完整生命周期

从按键到冷却结束，每步标注执行者（引擎/脚本）：

```
【输入】 按键（快捷栏槽位 或 .skl [command] 指令序列匹配）
   ↓ 引擎：登记"技能X的键已按下"
【门禁①】 checkCommandEnable_*（脚本）：当前状态能不能出招
【门禁②】 checkExecutableSkill_*（脚本）→ sq_IsUseSkill（引擎）：
          CD检查 → MP检查 → 密封/禁用检查 → 通过则【扣MP+进CD】
          （消耗修改窗口：useSkill_before/after 可微调倍率）
【切状态】 sq_AddSetStatePacket(状态ID, USER优先级, 带参)
          → 可被 addSetStatePacket_* 钩子驳回 → 广播全端
【初始化】 onSetState_*（脚本）：
          停移动 → 设动画（数字索引→查.chr→.ani）
          → 设攻击信息（→.atk）→ 设伤害（从.skl按等级取，百分比+固伤双轨）
          → setSkillSubState(段数) → 锁攻速
【执行】  引擎播动画 + 三种帧时机驱动脚本：
          · onKeyFrameFlag（.ani [SET FLAG] 标记帧回调）★主力
          · onProc/onProcCon（每帧轮询帧号）
          · onTimeEvent（定时器）
          脚本在这些回调里：创建PO弹道/爆炸、开连段输入窗、位移、震屏闪屏
【判定】  引擎扫【当前帧攻击盒×当前攻击信息】命中 → 回调 onAttack_*
          （脚本只追加：控制/特效/挂debuff/登记抓取）
【结束】  onEndCurrentAni_*（动画播完→回STAND）
          onEndState_*（真离开本状态→手动startSkillCoolTime（特殊技能）+清理）
```

**CD 两种机制**：默认 `sq_IsUseSkill` 成功即自动进 CD（.skl [auto cooltime apply]）；多段技能（三段斩）在 `onEndState` 手动启动（真离开才计时）。

## 2. 技能的四种形态（"内容载体"）

同一个框架，装四种东西——区别只在"伤害从哪出"：

| 形态 | 伤害怎么出 | 例子 | 触发时机 |
|------|-----------|------|---------|
| **① 本体直击**（近战挥砍） | 角色动画帧的攻击盒 × 本体攻击信息 | 三段斩、普攻 | 动画播到判定帧，引擎自动 |
| **② PO 被动物体**（弹道/爆炸/区域） | 脚本在标记帧创建 PO（参数包传伤害）→ PO 自己的 .ani 盒 × 自己的 .atk | 血爆、波动剑、火圈 | 脚本 onKeyFrameFlag 主动创建 |
| **③ Buff/附加**（Appendage） | 持续性效果（每tick扣血/属性修改），不即时 | 燃烧、出血、眩晕、变身 | 命中时挂（sq_AppendAppendage）或施放时挂自己 |
| **④ 召唤物** | 引擎级 Monster 实体 + 寄生 AI appendage | 召唤克鲁塔 | 施法读条完成 |

分界线：**近身即时→本体；远程/延迟/持续→PO；状态持续→Appendage；独立战斗实体→召唤。**（详见 05-复杂技能案例）

**Appendage（附加体）是万能副作用容器**：debuff/控制锁（hold）/召唤AI/变身形态/属性修改全是它。parent(宿主)/source(施与者) 双引用 + sq_SetValidTime 时限 + proc/onStart/onEnd 钩子。≈ 我们的 Buff 组件。

## 3. 连招与取消体系（叠在生命周期上的手感层）

取消四层级（从松到紧）：

```
① 柔化（学被动后）：任意技能任意帧可切其他技能——常驻appendage每帧proc轮询
② 普攻取消白名单：普攻中后段可被 cancelskilllist.co 列表内技能打断
③ 普攻段间推进：动画≥cancelStartFrame 后重按X → 下一段
④ 动画自然结束
```

- 普攻连段引擎原生推进（STATE_ATTACK=8，非技能），脚本用 `getAttackCancelStartFrame(N)` 回调控制"第几帧起可接下一段"。
- 每段 .atk 反应不同（attack1/2 推走 lift 75/90、attack3 击飞 DOWN+300）——**连招手感的数据层**。
- 指令输入（→+Z）：.skl [command] 声明，引擎匹配器逐序列记进度；手搓有 CD/MP 减免激励。
- 优先级铁律：玩家取消用 USER(1)；被击/倒地/抓取用 FORCE(3)/IGNORE_FORCE(4)——**任何连招都能被打断**。

## 4. 数据文件在技能里的角色（速览，详见 09）

| 文件 | 技能视角的作用 |
|------|--------------|
| .skl | 数值面：指令/CD/MP/每级伤害列（[level info] 列数+每级行） |
| .chr | 资源菜单：数字索引→动画/攻击信息路径 |
| .ani | 演出面：帧序列+盒子+标记+渲染效果（节拍器） |
| .atk | 命中面：浮空/击退/僵直/受击模式（盒不在这） |
| .nut | 行为面：什么时候用什么（本文的主角） |
| cancelskilllist.co | 手感面：普攻可取消技能白名单 |

## 5. 一个技能脚本的标准写法（模板）

```squirrel
// skillX.nut —— 一个文件可注册多个状态
function checkExecutableSkill_SkillX(obj)          // 出招检查
    if (obj.sq_IsUseSkill(SKILL_X))                 // 引擎校验+扣费+CD
        obj.sq_AddSetStatePacket(STATE_X, USER, false)

function onSetState_SkillX(obj, state, datas, isResetTimer)  // 进状态初始化
    obj.sq_StopMove()
    obj.sq_SetCurrentAnimation(CUSTOM_ANI_X)        // 设动画（查.chr）
    obj.sq_SetCurrentAttackInfo(CUSTOM_ATK_X)       // 设攻击信息
    obj.sq_SetCurrentAttackBonusRate(伤害%)          // 从.skl取
    obj.sq_SetCurrentAttackPower(固伤)
    obj.setSkillSubState(datas[0])                  // 连段段数

function onKeyFrameFlag_SkillX(obj, flagIndex)      // 帧标记回调（★主力）
    if (flagIndex == 1)  // 判定帧：创建PO/震屏/特效
        obj.sq_StartWrite(); ...WriteDword(参数)
        obj.sq_SendCreatePassiveObjectPacket(PO_ID, 0, 0, 0, z)

function onProc_SkillX(obj)                         // 每帧轮询（位移/输入窗）
function onAttack_SkillX(obj, damager, boundingBox) // 命中回调（追加效果）
function onEndCurrentAni_SkillX(obj)                // 动画完→回STAND
function onEndState_SkillX(obj, new_state)          // 真离开→CD+清理
```

**老技能 vs 新技能**：老技能（编号小）状态机在 C++ 引擎，.nut 只挂这些钩子；新技能（130+/220+）整条状态机（子状态 switch 推进）都在 .nut 里写。学新写法即可。

## 7. 一页速查

```
技能是什么？   状态机的一个状态 + .skl数值 + .nut脚本
怎么放？       按键→门禁→sq_IsUseSkill(扣费/CD)→切状态→播动画
判定哪来？     动画帧的攻击盒 × 当前攻击信息（引擎扫）
伤害哪来？     .skl按等级取 → 本体直击 or PO参数包 or Appendage tick
什么时候造特效？ 动画标记帧回调（onKeyFrameFlag）→ 脚本创建PO/纯视觉
连段怎么接？   段动画≥cancelFrame后重按/输入窗 → 带SubState切下一段
取消谁能打断谁？ 柔化>白名单>段间>自然结束；受击/抓取(FORCE)打断一切
脚本写什么？   check→onSetState→帧回调干活→onEndCurrentAni收尾（模板见§5）
```
