### 1.2 核心架构

**技能定义 = 代码（在 SkillDefs 项目里写），不是 Excel 配置表。**

ET-SkillSystem Demo（状态同步）把技能做成 Excel 配置表，那是因为 MMO 状态同步的技能由策划配表驱动。我们是帧同步，技能逻辑在客户端确定性执行，用 C# 代码写技能更灵活、更好调试、更容易保证确定性。

**Buff 的配置解释器模式参照 Demo 的 Actions 系统**：Buff 的效果（加减属性、施加伤害、施加子 Buff）通过 Actions 机制驱动。简单效果用已有 Action 组合，复杂效果写一个新的 ILSAction 实现类。

```
框架包（cn.etetet.skill）提供运行时基础设施：
  - LSNumericComponent（数值计算）
  - LSActionDispatcher（Action 分发）
  - LSShapeData（形状判定）
  - SkillLogic 基类 + SkillContext API
  - LSBuff 配置解释器（根据 BuffDef 定义执行 AddAction/TickAction/RemoveAction）
  - LSCast 时间轴驱动

SkillDefs 项目定义具体游戏内容：
  - 技能类（BurningZone、IceArrow、Charge...）
  - BuffDef 定义（每个 Buff 绑定哪些 Action、持续时间、Tick 间隔）
  - ILSAction 实现（NumericChange、Damage、CastBullet、Attract...）
  - NumericType 枚举（Speed、Hp、Attack...）
  - 所有 ID 常量（SkillIds、BuffIds、ActionIds）
```

```csharp
{
```

```csharp
    TSVector2 v2 = self.LSInput.V * 6 * 50 / 1000;

    unit.Forward = unit.Position - oldPos;
```

## 四、层③ — 技能系统框架包

### 4.1 LSNumericComponent — 数值组件

参照 ET 框架的 NumericComponent 设计（`Book/5.6数值组件设计.md`），适配帧同步（FP 替代 int）：

```csharp
[ComponentOf(typeof(LSUnit))]
[MemoryPackable]
public partial class LSNumericComponent : LSEntity, IAwake, ISerializeToEntity
{
    [MemoryPackOrder(0)]
    public Dictionary<int, FP> NumericDic = new();

    public FP Get(NumericType type) => GetByKey((int)type);

    public void Set(NumericType type, FP value)
    {
        int key = (int)type;
        NumericDic[key] = value;
        if (key % 10 != 0) UpdateFinal(key / 10 * 10);
    }

    public void Add(NumericType type, FP value) => Set(type, Get(type) + value);

    private FP GetByKey(int key)
    {
        NumericDic.TryGetValue(key, out FP value);
        return value;
    }

    // 五层公式：final = (((base + add) * (1 + pct) + finalAdd) * (1 + finalPct)
    private void UpdateFinal(int finalKey)
    {
        FP baseVal    = GetByKey(finalKey + 1);
        FP add        = GetByKey(finalKey + 2);
        FP pct        = GetByKey(finalKey + 3);
        FP finalAdd   = GetByKey(finalKey + 4);
        FP finalPct   = GetByKey(finalKey + 5);

        NumericDic[finalKey] = ((baseVal + add) * (FP.One + pct) + finalAdd) * (FP.One + finalPct);
    }
}
```

```csharp
public enum NumericType
{
    Max = 10000,

    Speed = 1000,
    SpeedBase = Speed * 10 + 1,
    SpeedAdd = Speed * 10 + 2,
    SpeedPct = Speed * 10 + 3,
    SpeedFinalAdd = Speed * 10 + 4,
    SpeedFinalPct = Speed * 10 + 5,

    Hp = 1001,
    HpBase = Hp * 10 + 1,

    MaxHp = 1002,
    MaxHpBase = MaxHp * 10 + 1,
    MaxHpAdd = MaxHp * 10 + 2,
    MaxHpPct = MaxHp * 10 + 3,
    MaxHpFinalAdd = MaxHp * 10 + 4,
    MaxHpFinalPct = MaxHp * 10 + 5,

    Attack = 1003,
    AttackBase = Attack * 10 + 1,
    AttackAdd = Attack * 10 + 2,
    AttackPct = Attack * 10 + 3,

    Defense = 1004,
    DefenseBase = Defense * 10 + 1,
    DefenseAdd = Defense * 10 + 2,
    DefensePct = Defense * 10 + 3,

    ForbidMove = 1005,     // 禁止移动（眩晕/冰冻用）
    ForbidSkill = 1006,    // 禁止施法
}
```

**与 ET-SkillSystem Demo 的 NumericComponent 对比**：

| 维度 | ET-SkillSystem（状态同步） | 本方案（帧同步） |
|------|--------------------------|-----------------|
| 值类型 | `long`（定点，乘 10000） | `FP`（TrueSync 定点数） |
| 公式 | `((base+add)*(100+pct)/100+finalAdd)*(100+finalPct)/100` | `((base+add)*(1+pct)+finalAdd)*(1+finalPct)` |
| 序列化 | 可选 | MemoryPack（快照回滚） |
| 事件 | `Game.EventSystem.Run` | 帧同步内不需要（确定性，无事件总线） |

**为什么用 ET 的 NumericComponent 而不是自定义 LSStatsComponent**：

1. 自定义组件字段写死（HP/Speed/Attack）——加属性改代码。NumericComponent 用 key-value，新属性加个枚举值
2. Buff 效果无法统一——MoveSpeedMod 要单独字段。NumericComponent 统一用 `Add(NumericType.SpeedAdd, value)`
3. ET 框架自带五层公式（base/add/pct/finalAdd/finalPct），复杂 buff（+50 速度再 +20%）自动计算

```csharp
{

    Damage = 2,          // 造成伤害
    CastBullet = 3,      // 发射弹道

{
    BuffAdd,        // Buff 添加时
    BuffTick,       // Buff Tick 时

    CastHit,        // Cast 命中时
    CastSelfHit,    // Cast 对自身命中时

// Action 处理器接口
public interface ILSAction
{
    void Run(LSUnit owner, int[] param, LSActionRunType runType);
}

// Action 注册特性
[AttributeUsage(AttributeTargets.Class)]
public class LSActionAttribute : Attribute
{
    public LSActionType Type { get; }
    public LSActionAttribute(LSActionType type) => Type = type;
}
```

#### Action 分发器

```csharp
public static class LSActionDispatcher
{
    private static readonly Dictionary<LSActionType, ILSAction> handlers = new();

    // 初始化时扫描所有 ILSAction 实现并注册
    public static void Init()
    {
        foreach (var type in typeof(LSActionDispatcher).Assembly.GetTypes())
        {
            if (typeof(ILSAction).IsAssignableFrom(type) && !type.IsAbstract)
            {
                var attr = type.GetCustomAttribute<LSActionAttribute>();
                if (attr != null)
                    handlers[attr.Type] = (ILSAction)Activator.CreateInstance(type);
            }
        }
    }

    public static void Run(LSUnit owner, int actionId, LSActionRunType runType)
    {
        var config = LSActionConfigCategory.Get(actionId);
        if (!handlers.TryGetValue((LSActionType)config.Type, out var handler)) return;
        handler.Run(owner, config.Param, runType);
    }

    // 批量执行
    public static void RunAll(LSUnit owner, int[] actionIds, LSActionRunType runType)
    {
        if (actionIds == null) return;
        foreach (int id in actionIds)
            Run(owner, id, runType);
    }
}
```

#### BuffDef — Buff 定义（在 SkillDefs 项目里）

每个 Buff 的定义就是一段代码，声明生命周期各阶段执行哪些 Action：

```csharp
            TickTime = 1000,

        BuffRegistry.Register(BuffIds.Transform, new BuffDef

public struct BuffDef
{
    public int TotalTime;           // 持续时间（ms）
```

```csharp
// LSCastSystem — 时间轴驱动
[LSEntitySystem]
private static void LSUpdate(this LSCast self)
{
    if (self.Finished) return;

    FP dt = LSConstValue.UpdateInterval;
    self.ElapsedMs += (int)(dt * 1000);

    var config = LSCastConfigCategory.Get(self.ConfigId);
    LSWorld world = self.LSWorld() as LSWorld;
    LSUnit caster = world.GetComponent<LSUnitComponent>().GetChild<LSUnit>(self.CasterId);

    // 推进时间轴：检查是否到了某个 HitAction 的时间点
    while (self.NextHitIndex < config.HitActionTimes.Length)
    {
        if (self.ElapsedMs < config.HitActionTimes[self.NextHitIndex]) break;

        // 触发命中 Action
        foreach (int actionId in config.HitAction)
        {
            foreach (long targetId in self.TargetIds)
            {
                LSUnit target = world.GetComponent<LSUnitComponent>().GetChild<LSUnit>(targetId);
                LSActionDispatcher.Run(target, actionId, LSActionRunType.CastHit);
            }
        }

        self.NextHitIndex++;
    }

    // 检查结束
    if (self.ElapsedMs >= config.TotalTime)
    {
        // 触发 FinishAction
        LSActionDispatcher.RunAll(caster, config.FinishAction, LSActionRunType.CastFinish);
        self.Finished = true;
    }
}
```

```csharp
// LSBuffComponentSystem — Buff 配置解释器
[LSEntitySystem]
private static void LSUpdate(this LSBuffComponent self)
{
    FP dt = LSConstValue.UpdateInterval;
    int dtMs = (int)(dt * 1000);
    LSUnit owner = self.GetParent<LSUnit>();

    foreach (LSBuff buff in self.Children.Values.ToList())
    {
        buff.RemainingMs -= dtMs;
        if (buff.RemainingMs <= 0)
        {
            // 移除：执行 RemoveAction
            var config = LSBuffConfigCategory.Get(buff.ConfigId);
            LSActionDispatcher.RunAll(owner, config.RemoveAction, LSActionRunType.BuffRemove);
            buff.Dispose();
            continue;
        }

        // Tick
        var buffConfig = LSBuffConfigCategory.Get(buff.ConfigId);
        if (buffConfig.TickTime > 0)
        {
            buff.TickTimer += dtMs;
            if (buff.TickTimer >= buffConfig.TickTime)
            {
                buff.TickTimer -= buffConfig.TickTime;
                LSActionDispatcher.RunAll(owner, buffConfig.TickAction, LSActionRunType.BuffTick);
            }
        }
    }
}
```

### 4.5 LSShapeData — 技能形状

支持圆形、矩形、扇形、环形：

```csharp
public enum LSShapeType
{
    Circle = 1,
    Rectangle = 2,
    Fan = 3,
    Ring = 4,
}

[MemoryPackable]
public partial struct LSShapeData
{
    [MemoryPackOrder(0)]
    public LSShapeType Type;

    [MemoryPackOrder(1)]
    public TSVector Center;

    [MemoryPackOrder(2)]
    public TSVector Direction;     // 扇形朝向

    [MemoryPackOrder(3)]
    public FP Radius;              // 圆形/环形外半径

    [MemoryPackOrder(4)]
    public FP InnerRadius;         // 环形内半径

    [MemoryPackOrder(5)]
    public TSVector HalfExtents;   // 矩形半尺寸

    [MemoryPackOrder(6)]
    public FP Angle;               // 扇形半角（度）

    [MemoryPackOrder(7)]
    public FP Range;               // 扇形范围

    // 判断点是否在形状内
    public bool Contains(TSVector point)
    {
        switch (Type)
        {
            case LSShapeType.Circle:
                return TSVector.Distance(Center, point) < Radius;

            case LSShapeType.Rectangle:
                return AABBUtil.FromCenter(Center, HalfExtents).Contains(point);

            case LSShapeType.Fan:
                TSVector toPoint = point - Center;
                FP dist = toPoint.Length();
                if (dist > Range || dist <= FP.Zero) return false;
                FP angle = TSVector.Angle(Direction, toPoint / dist);
                return angle < Angle;

            case LSShapeType.Ring:
                FP d = TSVector.Distance(Center, point);
                return d >= InnerRadius && d < Radius;

            default: return false;
        }
    }
}
```

```csharp
{
    private static readonly Dictionary<int, Func<SkillLogic>> factories = new();

    // 初始化：扫描程序集
    public static void Init()
    {
        // 开发期：直接扫描当前程序集
        // 发布期：扫描 HybridCLR 加载的 DLL
        foreach (var type in typeof(SkillLoader).Assembly.GetTypes())
        {
            if (!typeof(SkillLogic).IsAssignableFrom(type) || type.IsAbstract) continue;
            var attr = type.GetCustomAttribute<SkillIdAttribute>();

        // 同时初始化 Action 分发器
        LSActionDispatcher.Init();
    }

    public static SkillLogic Create(int skillId)
    {
        return factories.TryGetValue(skillId, out var f) ? f() : null;
    }
}
```

```csharp
{
    public override FP Cooldown => 5;
    public override FP Range => 800;
    public override int TotalFrames => 40;

    private TSVector _targetPos;
    private bool _reached;

    public override void OnCast(SkillContext ctx)
    {
        _reached = false;
        TSVector dir = ctx.TargetPosition - ctx.Caster.Position;
        if (dir.Length() > Range) dir = dir.normalized * Range;
        _targetPos = ctx.Caster.Position + dir;
        ctx.SetAttackHitbox(new TSVector(0, 0, 5), new TSVector(5, 5, 10));
    }

    public override void OnUpdate(SkillContext ctx, FP dt)
    {
        if (_reached) return;

        LSUnit caster = ctx.Caster;
        TSVector toTarget = _targetPos - caster.Position;
        FP moveAmount = 30 * dt;

        if (moveAmount >= toTarget.Length())
        {
            caster.Position = _targetPos;
            _reached = true;
        }
        else
        {
            caster.Position += toTarget.normalized * moveAmount;
        }

        foreach (LSUnit enemy in ctx.GetEnemies())
        {
            if (ctx.CheckHit(caster, enemy))
            {
                ctx.AddNumeric(enemy, NumericType.Hp, -100);
                ctx.MoveUnitTo(enemy, _targetPos);
            }
        }
    }

    public override void OnEnd(SkillContext ctx) => ctx.DisableAttackHitbox();
}
```

## 七、关键设计决策

### 7.1 为什么 skill 引用 lockstep 而不是反过来

skill 包的实体定义直接使用 lockstop 包的类型（`[ComponentOf(typeof(LSUnit))]`），所以 skill 必须引用 lockstep。lockstop 包通过 `ILSUpdate` 接口多态驱动 skill 实体，不需要知道具体类型。

### 7.2 为什么状态/属性在 skill 包，不在 lockstop 包

LSNumericComponent、LSBuffComponent 属于战斗系统概念，不是帧同步基础设施。一个没有技能的帧同步项目（如棋类）不需要它们。

眩晕阻止移动的问题：在 lockstep 自己的 LSInputComponent 上加 `MovementDisabled` bool。skill 包施加眩晕 Buff 时设置它。lockstop 只知道"可以移动/不能移动"，不知道 skill。

### 7.3 为什么用 ET 的 NumericComponent 而不是自定义属性组件

自定义组件字段写死（HP/Speed），加属性改代码。NumericComponent 用 key-value + 五层公式，Buff 效果统一通过 `Add(NumericType.SpeedAdd, value)` 操作，不需要每种 buff 效果一个字段。

### 7.4 为什么 buff 效果用 Actions 配置驱动而非硬编码

参照 ET-SkillSystem Demo 的 Actions 模式：简单 buff 用已有 Action 组合（NumericChange + Damage + AddBuff），复杂 buff 写一个新的 ILSAction 实现类。BuffDef 在 SkillDefs 代码里定义

### 7.5 为什么 Cast 用时间轴而非帧计数

ET-SkillSystem Demo 使用毫秒时间轴（HitActionTimes: [500, 1000]）。帧同步项目用 `ElapsedMs += dt * 1000` 累计时间，确定性一致。比帧计数更灵活（改帧率不影响技能节奏）。

### 7.6 为什么 LSAreaEntity 改为 LSShapeData

技能范围不只有矩形（AABB），还有圆形、扇形、环形。LSShapeData 统一所有形状，配置表选择形状类型 + 参数。
