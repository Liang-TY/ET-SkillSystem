# DNF 风格分层角色渲染方案

> 目标：把玩家从怪物资源（bantuamazones 单层）切换到鬼剑士（swordman 皮肤+武器 多层），为写鬼剑士技能做准备。分层架构一步到位——后期加上衣/下衣/鞋等图层只需放资源+加配置行，不改代码。

---

## 1. DNF 换装系统原理（实证）

DNF 角色是"纸娃娃"系统：**每个图层一张 img、帧号一一对应**。

```
第 N 帧 = body[N] + blade[N] + handle[N] + jacket[N] + ... 叠加渲染
```

**实测数据（鬼剑士 + 太刀）**：

| 图层 | img | 版本 | 帧数 | 帧 0 尺寸 | 帧 0 位置 | 画布 |
|---|---|---|---|---|---|---|
| 皮肤/身体 | sm_body0000.img | v4 ✓ | **242** | 71×107 | (189, 231) | 500×500 |
| 刀刃 | katana(1).img | v2 ✓ | **242** | 37×96 | (157, 253) | 500×500 |
| 刀柄 | katana.img | v2 ✓ | **242** | 11×13 | (194, 232) | 500×500 |

关键：**帧数完全相同**——每个动画帧号 N 在三张图集里都有对应的 sprite，按各自的画布内位置叠加。

**动画引用**：.ani 文件里 `[IMAGE]` 引用 `sm_body%04d.img`（格式串模板），运行时解析到实际装备的皮肤编号（0000 = 默认）。我们的翻译工具输出 `path = sm_body0000.img`（GetFileName）。

## 2. 与怪物系统的差异

| | 怪物（现状） | 玩家（目标） |
|---|---|---|
| 图层数 | 1（单 SpriteRenderer） | 3+（每层一个 SpriteRenderer） |
| 图集 | bantuamazones.img | sm_body0000 + katana(1) + katana + ... |
| attackBox | .ani 里有（帧驱动） | .ani 里**没有**——由 nut 脚本动态创建 |
| damageBox | .ani 里有 ✓ | .ani 里有 ✓（**不变**） |
| 渲染配置 | 无（单图集） | 分层列表（数据驱动） |

**attackBox 空缺的处理**：DNF 玩家攻击盒由 `sq_AddAttackBox` 在技能脚本里动态创建（数据在 `attackinfo/*.atk`，但那是伤害反应参数不是几何盒）。我们的方案：
- **已有的 `SetAttackHitbox(offset, halfExtents)` API 就是为这个设计的**——SkillLogic 的 OnCast/OnUpdate 里手动设攻击盒
- 未来接 DNF .nut 数据时，翻译工具可以解析 nut 里的 AddAttackBox 调用，自动生成每帧攻击盒数据
- 帧驱动路径继续支持（.ani 有 attackBox 就用，没有就不出）——两者兼容

## 3. 架构设计

### 3.1 渲染分层（视图层改动，逻辑层零改动）

```
当前：LSUnitView → 1 个 SpriteRenderer ← 1 张图集
改后：LSUnitView → N 个 SpriteRenderer（子 GO）← N 张图集（同一帧号）
```

```
LSUnitView（根 GO，定位）
├── Layer_body（子 GO + SpriteRenderer，sortingOrder = 0）← sm_body0000 图集
├── Layer_blade（子 GO + SpriteRenderer，sortingOrder = 1）← katana(1) 图集
└── Layer_handle（子 GO + SpriteRenderer，sortingOrder = 2）← katana 图集
```

### 3.2 分层配置（数据驱动，不改代码换装）

```csharp
// ModelView：LSUnitView 加字段
public class LSUnitView : Entity, ...
{
    // ... 已有字段 ...
    public UnitRenderConfig RenderConfig;   // 分层渲染配置
}

// 渲染配置类
[EnableClass]
public class UnitRenderConfig
{
    public List<RenderLayer> Layers = new();
}

[EnableClass]
public class RenderLayer
{
    public string AtlasName;      // 图集名（= img 文件名，如 "sm_body0000.img"）
    public int SortingOrder;      // z 序（越大越前）
    public SpriteRenderer Renderer;  // 运行时创建
    public Material OriginalMaterial; // 材质缓存（加法混合切换用）
}
```

### 3.5 逻辑层（几乎零改动——仅受击动画分流）

| 系统 | 变化 |
|---|---|
| LSAnimComponent（动画推进） | **零改动**——帧号照旧 |
| LSHitboxComponent（受击盒采样） | **零改动**——damageBox 照旧从 json 采样 |
| 攻击盒 | **零改动**——.ani 有 attackBox 就采样，没有就不出 |
| 碰撞检测 | **零改动**——AABB 相交照旧 |
| 技能框架 | **零改动**——Cast/SkillContext/ContentLoader 跟渲染无关 |
| 投射物/区域 | **零改动**——独立视图 |
| **受击动画** | **要改**——每个单位自带 HurtAnimId（不能全局硬编码） |
| **普攻动画** | **要改**——NormalAttack 从 AnimId.Attack1 换成 SwordmanAttack1 |

### 3.6 受击动画分流（DNF `sq_GetDamageAni` 同构）

DNF 做法：引擎调 `obj.sq_GetDamageAni(index)` ——**向目标对象问"你的受击动画是什么"**，每个角色/怪物自带 damage.ani。

我们的做法（同构）：

```
LSCombatComponent 加 HurtAnimId 字段（int，0 = 未配置）
├── 工厂按角色设值：
│   ├── 怪物（bantu）→ HurtAnimId = AnimId.Hurt（damage.json）
│   └── 玩家（swordman）→ HurtAnimId = AnimId.SwordmanHurt（swordman_damage.json）
├── MeleeHitAction：
│   ctx.PlayOwnerAnim(ctx.GetOwnerHurtAnimId())
│   → 有配置就播动画
│   → 0 或动画未注册 → 不播动画，由红闪兜底
└── 红色闪白：只在"没有受击动画"时触发（互斥，不叠加）
```

**三种场景的实际效果**：

| 场景 | 受击动画 | 红色闪白 | 视觉反馈 |
|---|---|---|---|
| 怪物被打 | ✓ 播 damage.json | ✗ 不闪 | 动画 |
| 玩家被打 | ✓ 播 swordman_damage.json | ✗ 不闪 | 动画 |
| 某角色没配 HurtAnimId | ✗ 不播 | ✓ 红闪 | **红闪兜底** ✓ |

**互斥逻辑**：LSCastViewComponentSystem 的闪白触发条件从 `hp < lastHp` 改为 `hp < lastHp && 该单位 HurtAnimId == 0`——有受击动画就只播动画，没受击动画才红闪。

**改动量**：LSCombatComponent 加 1 字段 + LSActionContext 加 1 方法 + MeleeHitAction 改 1 行 + 工厂设值 2 行 + 闪白互斥判断 1 行 ≈ 6 行。

### 3.7 现有技能影响评估

| 技能/节点 | 引用什么动画 | 要改吗 |
|---|---|---|
| **NormalAttack** | `AnimId.Attack1`（kneekick.json） | **要**：改 `AnimId.SwordmanAttack1` |
| **MeleeHitAction** | `AnimId.Hurt`（damage.json） | **要**：改 `ctx.GetOwnerHurtAnimId()`（见 §3.6） |
| TestCooldownSkill | 无动画引用 | **不改** |
| WaveSwordSkill | 无动画引用 | **不改** |
| FireCircleSkill | 无动画引用 | **不改** |
| FireDamageTickAction | 无动画引用 | **不改** |
| ForbidMoveActions | 无动画引用 | **不改** |

**结论：4/7 技能零改动**。技能框架本身是动画无关的——这次切换验证了架构解耦。

### 3.8 AnimId 常量规划

```
// 通用（怪物/特效）
None = 0, Idle = 1(bantu), Walk = 2(bantu), Attack1 = 3(kneekick), Hurt = 4(bantu damage)
NormalWave = 5, FireCircle = 6, FireCircleEnd = 7

// 鬼剑士（玩家专用段，10 起）
SwordmanIdle = 10      → swordman_stay.json
SwordmanWalk = 11      → swordman_move.json
SwordmanAttack1 = 12   → swordman_attack1.json
SwordmanAttack2 = 13   → swordman_attack2.json
SwordmanAttack3 = 14   → swordman_attack3.json
SwordmanHurt = 15      → swordman_damage.json
SwordmanBloodboom = 16 → swordman_bloodboom.json
```

注册在 LSAnimClipRegistrar（同现有模式），图集 key 按各自 json 里的 image.path 文件名。

## 4. 实施计划

### 第零步：受击动画分流基建

1. `LSCombatComponent` 加 `HurtAnimId` 字段
2. `LSActionContext` 加 `GetOwnerHurtAnimId()` 方法
3. `MeleeHitAction` 改用 `ctx.GetOwnerHurtAnimId()`
4. 工厂分流（怪物 HurtAnimId=AnimId.Hurt，玩家 HurtAnimId=AnimId.SwordmanHurt）
5. `NormalAttack` 改用 `AnimId.SwordmanAttack1`

### 第一步：翻译鬼剑士动画（DnfConfigTranslation）

翻译以下 .ani → json（放到 Bundles/AnimRes/）：
- `stay.ani` → `swordman_stay.json`（Idle，7 帧，12 damageBox）
- `move.ani` → `swordman_move.json`（Walk，9 帧，8 damageBox）
- `attack1.ani` → `swordman_attack1.json`（普攻1，11 帧，33 damageBox，0 attackBox）
- `attack2.ani` → `swordman_attack2.json`（普攻2，12 帧，44 damageBox）
- `attack3.ani` → `swordman_attack3.json`（普攻3，10 帧，29 damageBox，2 attackBox）
- `damage1.ani` → `swordman_damage.json`（受击，2 帧，2 damageBox）
- `bloodboom.ani` → `swordman_bloodboom.json`（技能，24 帧，23 damageBox）

### 第二步：图集入库

复制 img 到 Bundles/AnimRes/（同 bantuamazones 流程）：
- `sm_body0000.img.bytes`（v4，242 帧）
- `katana(1).img.bytes`（v2，242 帧）
- `katana.img.bytes`（v2，242 帧）

### 第三步：视图层改造

1. LSUnitView 加 RenderConfig 字段
2. LSUnitViewComponentSystem.InitAsync 创建分层子 GO
3. LSSpriteAnimViewComponentSystem.Update 遍历层渲染
4. 受击闪白遍历层设颜色
5. LSAnimResComponentSystem 加载三张新图集

### 第四步：玩家工厂切换 + 受击分流

- npkparser 加 AnimId 常量段（SwordmanIdle=10 起，见 §3.8）
- LSUnitFactory：玩家 `DefaultAnimId = AnimId.SwordmanIdle`、`HurtAnimId = AnimId.SwordmanHurt`
- RoomSystem：怪物照旧 `DefaultAnimId = AnimId.Walk`、`HurtAnimId = AnimId.Hurt`
- NormalAttack（DotNet~）改 `ctx.PlayAnim(AnimId.SwordmanAttack1)`
- MeleeHitAction（DotNet~）改 `ctx.PlayOwnerAnim(ctx.GetOwnerHurtAnimId())`

### 第五步：验证

- 玩家显示鬼剑士（皮肤+太刀分层渲染，走路/待机时身体和武器同步动）
- 普攻播放 swordman_attack1 动画（鬼剑士挥刀，刀跟随）
- J 命中怪物：怪物播 bantu 受击动画 + 红闪（照旧）
- 玩家被打（如果加个测试怪攻击的话）：玩家播 swordman 受击动画 + 红闪
- I 波动剑 / O 火圈 / K 自眩晕：照旧（回归）
- 怪物照旧 bantu 单层渲染（回归）
