## 0. 红线（违反 = 批次作废重做）

1. **严禁 pvf 全树扫描**。`rg`/`find`/`grep -r` 打在 pvf 根目录上单次 2 分钟起步，
   且重型扫描会令子 agent 静默死亡（本机实测）。所有检索必须限定在 §1.2 白名单子目录内，
   且优先 `ls` 目录按文件名直取，其次才目录内 grep。
   例外（试点补充）：注册行/常量表/引用链**直接指向**的白名单外单个文件（如剑影参照脚本
   `atswordman\...`）允许 cat/sed 定点读；但仍禁止对白名单外目录做任何递归扫描。
2. **只写分析文档**。游戏仓库内只允许新增 `Notes/技能实现/鬼剑士技能解析/<ID>-<名字>.md`；
   游戏仓库与翻译工具仓库（`E:\Projects\cs\parse-img-ani`）的任何代码/资源/其他文档都禁止改动。
   翻译工具的更新是主循环汇总缺口后的后续任务，agent 只负责**上报缺口**。
3. **存在性必须实测**。关联文件表每一行都要真的 ls/grep 过；找不到就写"缺失"，
   确实无法判定的标"未考证"，禁止臆造路径。
4. 路径含中文与空格，命令里必须整体加引号。
5. **读不到就记录跳过，不硬磕**。某个文件缺失不影响其余技能的分析。

### 2.2 仓库侧使用规则

1. **判定必须有代码依据**：写"✅ 直接可实现"前，先在 SkillLogic/SkillContext/各 Definition
   里确认要用的 API/字段真实存在（grep 方法名）；写"🔶/⛔"前，确认缺的东西确实不在框架层。
   §6.3 能力对照表只是索引，**以代码为准，文档可能滞后**。
2. **复用优先**：动手判定前先查已有内容件——新技能要的 Buff/Action/Area 若与先例同构
   （如新异常 Buff ≈ BleedBuff），草案里写"复制 X 改数值"，不要发明新机制。
3. **草案写真实类名**：文档 §5 的内容件清单必须是"继承真实基类 + 用真实 ctx 方法"的表述，
   例如"新建 XxxSkill : SkillLogic，OnCast 里 ctx.PlayAnim(新 AnimId)，OnUpdate 帧 22 处
   ctx.CreateAreaInFront(AreaIds.Xxx, 距离)——同 BloodBoomSkill 范式"。
4. **数值可落地**：HitReaction/CD/时长等给出"DNF 原值 + 我们 demo 建议值"两列
   （换算规则参考 01§4：如 DNF 像素→我们单位的比例、ms 直用）。
5. **翻译环节也要判**：技能涉及的 .ani/.als 里出现 README 翻译规则表之外的节/字段
   （如 `[IMAGE ROTATE]`、`[MIX FRAME]`…），或涉及尚无子命令的文件类型
   （.atk/.act 数据量大到不该手抄时），在文档「翻译工具适配」节列明：
   什么节、出现在哪个文件、建议加成什么 JSON 字段或新子命令。
   这是 DnfConfigTranslation 迭代的输入，缺口最终由主循环汇总成更新任务。

## 5. 单技能分析流程（A/B 九步；C/D/E 按 §4 降减）

`<pvf>` = pvf 根路径占位。命令均已实测。前置：§2 仓库必读已完成。

**Step 1 读 .skl**
```bash
grep -A1 "^\[name\]\|^\[name2\]\|^\[required level\]\|^\[type\]\|^\[command\]\|^\[cool time\]\|^\[maximum level\]" "<pvf>\skill\Swordman\<文件>.skl"
sed -n '1,60p' "<pvf>\skill\Swordman\<文件>.skl"    # 顺带看 explain/消耗/level property 各节
```
记录：中文名/英文名/等级/类型/指令/CD/MP/特殊消耗（HP 等）/
level property 等级数据各列含义（列号 → nut 里 `sq_GetLevelData(skillID, index, level)` 怎么取用）。

**Step 2 查状态注册 → 拿 nut 路径**
```bash
grep -n "<技能名小写>" "<pvf>\sqr\character\swordman_load_state.nut"
```
注册行形如：
`IRDSQRCharacter.pushState(ENUM_CHARACTERJOB_SWORDMAN, "character/swordman/bloodboom/bloodboom.nut", "swordman_bloodboom", 229, 229)`
——第 2 参是 nut 相对路径（相对 `sqr/`）；**第 4 参是状态号、第 5 参才是技能 ID**（-1=不绑定；
R1-A3 修正，详见 `_轮间经验.md` L2，按技能 ID 反查要 grep 第 5 参位置）。
注意：nut 目录名与技能名不一致是常态，**一切以注册行为准**；有些技能共用一个 nut（如 attack.nut）。

**Step 3 读主 nut（核心）**
```bash
ls "<pvf>\sqr\character\swordman\<nut目录>"
sed -n '1,120p' "<pvf>\sqr\character\swordman\<nut目录>\<技能>.nut"   # 长文件分段读完
```
走读四大回调并记录时序：
- `onSetState` 施法瞬间（播动画/设攻击信息/扣消耗/播特效音效）
- `onKeyFrameFlag(obj, flag)` .ani SET FLAG 帧触发（创建被动对象/追加行为）
- `onProc` 每帧（位移/蓄力/连打窗口判定）
- `onEndCurrentAni` 收尾（回待机/切子状态）

所有 `sq_` 关键调用逐条翻译成一句话语义：
`sq_SetCurrentAnimation(ID)`（播哪个 ani，ID 回 .chr 查）/
`sq_SetCurrentAttackInfo(ID)`（用哪个 .atk）/
`sq_SendCreatePassiveObjectPacket(ID, x, y, z, …)`（创建什么判定体，参数含义）/
`sq_GetLevelData` / `sq_CreateAppendage`（挂什么状态）/
`sq_SetMyShake` / `sq_PlaySound`（延后特性，标注即可）。

**Step 4 被动对象（若有）**
从 Step 3 的 CreatePassiveObject ID/名字找 `ap_<技能>.nut`（先在 `sqr\character\swordman\` 白名单内按文件名 grep），
再看 `passiveobject\character\swordman\animation\<技能名>\` 特效清单与 `action\<技能名>.act`。
记录：攻击盒创建（sq_AddAttackBox 参数即判定范围）、命中参数写入、生命周期、
多段重置/穿透/飞行/落地等行为。

**Step 5 角色动画与关键帧**
```bash
grep -n -i "<技能名>" "<pvf>\character\swordman\swordman.chr"
grep -c "^\[FRAME" "<pvf>\character\swordman\animation\<技能>.ani"
grep -n "SET FLAG\|ATTACK BOX\|DAMAGE BOX\|IMAGE RATE\|RGBA" 同文件
```
记录：帧数/分段帧时长/SET FLAG 的帧号与值（→ 触发时机）/有无攻击盒/受击盒覆盖帧/
有无 RGBA 染色与 IMAGE RATE 缩放（延后特性，标注）。
⚠ .ani 是 CRLF 文本，`grep -A1`/`paste`/`awk` 提取帧表会因 `\r` 失灵——
用 `_轮间经验.md` C1 的 python 一行式提取（帧号/delay/flag/攻击盒）。

**Step 6 .atk 命中反应**
```bash
ls "<pvf>\character\swordman\attackinfo" | grep -i "<技能名>"
cat "<命中的.atk>"
```
记录 damage bonus / attack type / push aside / lift up / direction / damage reaction
——这是我们 HitReaction（Damage/HitstunMs/KnockbackX/LaunchY）的数据源，直接给换算建议。

**Step 7 .als 边车（若存在）**
```bash
ls "<pvf>\character\swordman\animation" | grep -i "<技能名>"
cat "<...>.ani.als"     # 被动对象动画同理查 passiveobject\...\animation\<技能>\
```
记录 `[use animation]` 注册的特效 ani 与 `[add]` 挂接表（帧/层/别名）；
无贴图的空占位动画标注"可跳过"。

**Step 8 两侧资源对照汇总**
```bash
grep -h "\.img\|\.IMG" <该技能用到的所有 .ani 与 .als 文件> | sed 's/.*`\([^`]*\)`.*/\1/' | sort -u
ls "E:\Projects\cs\et9lockStepYIUITest\Packages\cn.etetet.lockstep\Bundles\AnimRes" | grep -i "<关键词>"
grep -n "public const int" "E:\Projects\cs\et9lockStepYIUITest\Packages\cn.etetet.npkparser\Runtime\AnimConfigRegistry.cs" | grep -i "<关键词>"
```
