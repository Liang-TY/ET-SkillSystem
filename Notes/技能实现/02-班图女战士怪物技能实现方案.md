## 4. 框架改动（阶段1）

### 4.1 确定性概率（LSRng）
随机种子思路（用户确认）：种子确定 → 序列确定 → 回放一致。实现为**无状态纯函数**（比"固定种子+Random 对象"少一份快照状态）：
```csharp
// ET.Skill Runtime/LSRng.cs
public static class LSRng
{
    /// (帧号, 单位Id, 用途Id) → [0,100)。splitmix32 整数混合。
    /// 同帧同单位同用途结果恒定（一帧内同单位同用途只 roll 一次——命中去重后天然满足）。
    public static int Roll(int frameNo, long unitId, int purpose) { ... }
}
```
消费点：MeleeHit 的 ProcStatus、阶段2 AI 选招/反击。

### 4.2 HitReaction 加 ProcStatus（DNF [active status] 同构）
```csharp
public int ProcBuffId;    // 0=无；命中按概率附加的 Buff（出血/冰冻…）
public int ProcChance;    // 概率 %（0-100）
```
MeleeHitAction：`if (r.ProcBuffId != 0 && LSRng.Roll(...) < r.ProcChance) ctx.AddBuffToOwner(r.ProcBuffId);`
v1 简化：时长/每跳伤害用 Buff 预设（不随 .atk 参数化），记档 §9。

### 4.3 新 Buff
- **FreezeBuff（冰冻）**：3.5s ForbidMove（Stun 同构）；冰冻期间受击不重置硬直的细化延后。
- 出血复用现有 BleedBuff。

### 4.4 怪物可施放 + 工厂化
- 怪物补挂 `LSSkillComponent + LSCastComponent`（走玩家同款 Cast 框架：CD/硬直门禁/帧驱动攻击盒全白嫖）。
- RoomSystem 里的桩抽成 `LSMonsterFactory.Create()`；`DefaultAnimId` 从 Walk 改 **Stay（复用 AnimId.Idle=1，stay.json 已在库）**。
- **临时轮播驱动（阶段1 测试，阶段2 删）**：`LSMonsterDebugDriverComponent`（计时器+技能轮播序号），每 3s `SkillCastHelper.TryCast(monster, 下一个技能)`。

### 4.5 受击链闭环（击倒落地 → 起身）
- `LSCombatComponent` 加 `DownAnimId`（0=未配置）；`LSFlightComponentSystem` 落地时：`Play(DownAnimId)` + `HitstunTimer = max(当前, Down 时长 900ms)`。
- `LSCombatComponentSystem` 硬直结束回默认的条件扩展：`anim.AnimId == HurtAnimId || anim.AnimId == DownAnimId`。
- Overturn（起身动画，rot160°）：**跳过**——旋转标签未支持，Down 播完直接切 Stay（记档 §9）。
- 非 lift 受击照旧（Hurt 动画+硬直）。

### 排查实录：怪物"放出全技能"（2026-08-22）
轮播驱动的 `index % RotationCount switch {...}` 因 **switch 表达式作右操作数优先级高于 %**，实际编译为 `index % (RotationCount switch{...})` = `index % 10`——怪物循环放 skill 1-9（含玩家技能），跳过 0 和 10。通过编译期常量自检日志（同 dll 内常量对/行为错 → 排除陈旧产物 → 锁定表达式语义）定位。修复 = 一对括号 `(index % RotationCount) switch`。**教训：switch 表达式当取模/三元条件时必须加括号**；另：ET.Hotfix 禁数组字段的 ET0004 修复把它从数组改成 switch 时引入——审查建议的 fixHint 语法本身就带着这个坑。

### 10.3 简化决策（已获用户授权，不要过度还原）

| DNF 行为 | 我们的做法 |
|---|---|
| [close-carefully] 谨慎贴近（绕圈/犹豫/后撤步） | **不做**——简化为直线接近目标 |

| 反击（被击 5% LowKick 突进） | 简单版：被击命中时 LSRng roll 5% → 直接 TryCast LowKick（硬直门禁天然限制：被击硬直中放不出来，需在硬直结束后补触发或直接放弃——**建议放弃**，收益低成本高，记档跳过） |
| 台词/掉落/抗性/精英化水属性/int data/stuckbonus | 全部跳过 |

### 10.4 实现形态：行为机（锁步翻译）+ 第六类内容（配置驱动）⭐

> **ET 的 AI 设计**见 `Book/6.1AI框架.md`、`6.2AI框架-行为机.md`（仓库无实现代码，只有方法论文档——已核实）。
> 行为机思想：互斥行为节点（不拆太细）+ 只看当前条件（无网状转移）+ 条件满足打断上一个。
> 原文的协程实现**不能进锁步世界**（墙钟 Wait/调度顺序/快照外状态 → desync+回滚炸），翻译规则：

| 行为机概念 | 锁步等价物 |
|---|---|
| `while+await` 行为协程 | 行为局部状态**存组件字段（进快照）**+ 每逻辑帧 `Tick()` 推一步 |
| `cancelToken.Cancel()` 打断 | 切节点时 `ResetBehavior()` 清局部字段 |
| `Wait(N)` | `TimerMs -= LSConstValue.UpdateInterval` 计数 |
| 调度器每秒重估条件 | `ThinkTimerMs` 帧节流（按优先级扫条件表） |

#### 10.4.1 配置驱动 = 第六类内容（MonsterAiDefinition，用户定案 2026-08-22）

**全部数值进配置类，AI System 零常量**。复用 ContentLoader 机制（同 Skill/Buff/Action/Bullet/Area），
零新包零新程序集：

```
cn.etetet.skill/Runtime/（ET.Skill，F6）          cn.etetet.skill/DotNet~/（ET.SkillContent）
  MonsterAiDefinition.cs：                           Monsters/BantuAmazonesAi.cs
    MonsterAiIdAttribute + MonsterAiIds                [MonsterAiId(MonsterAiIds.BantuAmazones)]
    MonsterAiDefinition 基类（数值全虚属性）             public class BantuAmazonesAi : MonsterAiDefinition
    MonsterAiLoader（ContentLoader 薄壳 5 行）            { override DNF 数据 }
cn.etetet.lockstep/Scripts/Model+Hotfix/Share/
  LSMonsterAIComponent(.cs/.System)：MonsterAiId + 运行状态（进快照）
```

**基类字段（默认值全部来自 .mob/attack kind，行内注明出处）**：

```csharp
public abstract class MonsterAiDefinition
{
    public virtual FP SightRange => 6;              // .mob [sight] 600px
    public virtual FP MoveSpeed => 4;               // .mob [move speed] 1000 → demo 换算
    public virtual int MoveAnimId => AnimId.Walk;
    public virtual int IdleAnimId => AnimId.Idle;
    public virtual int ThinkIntervalMs => 1000;     // 行为重估节流
    public virtual int AttackIntervalMs => 800;     // .mob [attack delay]
    public virtual int[] MeleeSkillIds => null;     // 近战池（attack kind 权重>0 的）
    public virtual int[] MeleeWeights => null;      // 对应权重（LSRng 加权选）
    public virtual FP MeleeRange => (FP)115 / 100;  // 近战触发距离
    public virtual int RangedSkillId => 0;          // 远程先手（0=无）
    public virtual FP RangedMinRange => (FP)12 / 10;
    public virtual FP RangedMaxRange => 6;          // ≤ SightRange
    public virtual FP HomeReturnRange => 0;         // 0=不返回
}
```

**为什么 C# Definition 而不是 json**：内容 DLL 两端加载天然同源（json 只有客户端场景切换加载，
服务端不加载——rngSeed 缺口就是这个问题，§9 记档）；改数值 = 改类 → ET/Skill/Compile 秒级不碰
Unity 编译；守门员无状态检查自动生效；新怪=新类一个文件；luban 迁移与五类内容同路径。

#### 10.4.2 AI System 行为机 Tick（System 零常量，全读 def）

```
LSMonsterAIComponent（快照内）：MonsterAiId（int）、CurrentNode（0=Idle/1=ChaseAttack）、
  TargetId（long）、ThinkTimerMs、AttackTimerMs

LSUpdate（每逻辑帧 50ms）：
  0. 硬直/倒地（HitstunTimer>0）→ return（受击系统接管=天然打断）
  1. ThinkTimer 到点（def.ThinkIntervalMs）：重估节点——
     视野（def.SightRange）内有玩家单位（最近的带 LSInputComponent 的）→ ChaseAttack，锁定 TargetId
     否则 → Idle；节点变化 → 清状态 + [MonsterAI] 日志
  2. Tick 当前节点：
     Idle：播 def.IdleAnimId
     ChaseAttack（追击+攻击一个节点，移动是行为的一部分——不拆细）：
       目标失效 → 本帧 return（等 Think 重估）
       有活动 cast → return（技中移动锁；玩家侧同款 attacking 检查）
       dist = |target.x - self.x|（x 轴距离）
       · dist > def.MeleeRange：Forward 朝目标；Position += 朝向×def.MoveSpeed×dt；播 Walk（防重启：!= 才 Play）
       · def.RangedMinRange < dist ≤ def.RangedMaxRange 且 def.RangedSkillId>0：TryCast(RangedSkillId)
       · dist ≤ def.MeleeRange：AttackTimer 到点（def.AttackIntervalMs）→ LSRng 加权选 def.MeleeSkillIds
```
