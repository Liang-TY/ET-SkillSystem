### Step 3：ParametricSkillLogic（框架层，读参数驱动全过程）

把现有技能逻辑的过程逻辑收敛成一个参数驱动基类。注册协议不改，仍由每个 SkillId 的无状态
薄子类交给 SkillLoader 反射注册；基类执行时按当前 cast 的整数 skillId 查询参数：

```csharp
[SkillId(SkillIds.HardAttack)]
public sealed class HardAttackSkill : ParametricSkillLogic
{
    public override int ConfiguredSkillId => SkillIds.HardAttack;
}
```

基类负责 OnCast/OnUpdate 的 phase、movement、manualBoxes、spawnEvents、HitReaction 和时序；
特殊技能可继承覆写并在对照表注明。这里不是把一个“通用执行器实例”动态注册成所有技能，
也不向逻辑实例写入可变配置状态。

- 特殊逻辑技能允许继承覆写（NormalAttack 空中分支、ChargeCrash 撞停细节等）——
  迁移时能参数化就参数化，不能的继承并注明
- **参数从哪读**：SkillLoader 仍按 [SkillId] 注册每个技能的无状态薄子类；ParametricSkillLogic
  用 ConfiguredSkillId（或当前 cast.SkillId）按整数查询 SkillParam。名称仅用于 Editor 显示和文件名。
