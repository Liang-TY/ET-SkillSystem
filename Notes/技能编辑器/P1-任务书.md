### Step 3：ParametricSkillLogic（框架层，读参数驱动全过程）

把现有 19 个 SkillLogic 的过程逻辑收敛成一个参数驱动类：

```csharp
[SkillId(id)]  // id 从参数注入——注册方式见 Step 4
public class ParametricSkillLogic : SkillLogic
{
    // OnCast:  清命中表 → 按 spawnEvents(atMs=0) → 进入 phase 0（PlayAnim/霸体/位移标记）
    // OnUpdate: 段内时间 = ElapsedMs - Phase(段起点)；
    //   - movement: 逐帧 MoveCasterForward（stopOnHit → ctx.AnyEnemyHit() 即停）
    //   - manualBoxes: onMs/offMs 窗口 SetAttackHitbox/Disable
    //   - spawnEvents: atMs 到点一次性触发（createArea at=self/inFront、createBullet、superArmor）
    //   - cancelMs: 缓冲消费（nextTrigger=key 时跨技能转派——P1 先不做转派，字段留 0）
    //   - phase 末: 下一段（PlayAnim/ClearHitTargets/Phase 重置）或 EndCast
    // HitReaction: hitReactions[SubState]（PhaseHitReaction override）
    // 总时长保险丝: totalTimeMs（P1 各技能直接抄现有值）
}
```

- 特殊逻辑技能允许继承覆写（NormalAttack 空中分支、ChargeCrash 撞停细节等）——
  迁移时能参数化就参数化，不能的继承并注明
- **参数从哪读**：SkillLoader 注册时按 name 关联 SkillParam 实例（ContentIds 双表查）
