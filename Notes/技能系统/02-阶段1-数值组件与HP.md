## 0. 速查

## 1. 做什么

### 1.1 LSNumericComponent（框架包 Model/Share）

```csharp
[ComponentOf(typeof(LSUnit))]
[MemoryPackable]
public partial class LSNumericComponent : LSEntity, IAwake, ISerializeToEntity
{
    [MemoryPackOrder(0)]
    public Dictionary<int, FP> NumericDic = new();

    public FP Get(int key)
    {
        NumericDic.TryGetValue(key, out FP value);
        return value;
    }

    public void Set(int key, FP value)
    {
        NumericDic[key] = value;
        if (key % 10 != 0) UpdateFinal(key / 10 * 10);
    }

    public void Add(int key, FP value) => Set(key, Get(key) + value);

    // 五层公式：final = (((base + add) * (1 + pct) + finalAdd) * (1 + finalPct)
    private void UpdateFinal(int finalKey)
    {
        FP baseVal  = Get(finalKey + 1);
        FP add      = Get(finalKey + 2);
        FP pct      = Get(finalKey + 3);
        FP finalAdd = Get(finalKey + 4);
        FP finalPct = Get(finalKey + 5);
        NumericDic[finalKey] = ((baseVal + add) * (FP.One + pct) + finalAdd) * (FP.One + finalPct);
    }
}
```

### 1.2 NumericType 常量（框架包 Model/Share）

```csharp
public static class NumericType
{
    public const int Hp = 1001;          public const int HpBase = 10011;
    public const int MaxHp = 1002;       public const int MaxHpBase = 10021;
    public const int Attack = 1003;      public const int AttackBase = 10031;
    public const int Defense = 1004;     public const int DefenseBase = 10041;
    public const int Speed = 1000;       public const int SpeedBase = 10001;
    public const int ForbidMove = 1005;  // 独立标记，非五层
    public const int ForbidSkill = 1006;
}
```

> lockstep 包也建一份同名的 `NumericType.cs`（只含 ForbidMove/ForbidSkill），值必须与此一致。

> **DNF 坐标系对照**（阶段 2 受击盒采样用，提前记住）：我们 TSVector(x=横向, y=高度, z=纵深)，1 单位=100px。DNF→我们映射：`我们.x ← DNF.x`（右正）；`我们.y ← DNF.z`（高度，上正，0=地面）；`我们.z ← DNF.y`（纵深）。**除以 100**。采样公式见阶段 2 文档。

### 1.3 给 unit 挂数值组件

在 `LSUnitFactory.Init`（玩家）和 `RoomSystem.Init`（怪物）里加：

```csharp
// 玩家（LSUnitFactory.Init）
var num = lsUnit.AddComponent<LSNumericComponent>();
num.Set(NumericType.HpBase, 1000);   // 基础 HP
num.Set(NumericType.MaxHpBase, 1000);

// 怪物（RoomSystem.Init 建怪物后）
var num = monster.AddComponent<LSNumericComponent>();
num.Set(NumericType.HpBase, 500);
num.Set(NumericType.MaxHpBase, 500);
```

## 2. 验证

进场景 Play，Console 加临时 Log（LSUnitFactory / RoomSystem 建完 unit 后）：

```csharp
Log.Info($"[Numeric] 玩家 HP = {num.Get(NumericType.Hp)}");
Log.Info($"[Numeric] 怪物 HP = {num.Get(NumericType.Hp)}");
```

**通过判据**：Log 打出 `玩家 HP = 1000`、`怪物 HP = 500`。

测试五层公式：临时 `num.Add(NumericType.HpBase, 100)` → HP 变 1100（base 变）。

**阶段3时发现的bug（2026-08-17 已修）**：原 `Set` 的 `key % 10 != 0 → UpdateFinal(key/10*10)` 与 NumericType 布局（子属性=final*10+1~5）不匹配——HpBase=10011 被算到孤儿 key 10010，`Get(Hp=1001)` 恒返 0，五层映射从未生效。修正：`key >= 10000 → UpdateFinal(key/10)`，`UpdateFinal` 读 `finalKey*10+1~5`，final key 直写不重算。详见 04-阶段3 修正记录。
