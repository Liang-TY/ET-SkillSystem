# 阶段 2：受击盒与碰撞检测

> 怪物有受击盒（从动画帧的 damageBox 采样），玩家有攻击盒，两者能做相交检测。

## 0. 速查

- **目标**：`LSHitboxComponent`（每帧从 `LSAnimComponent.GetCurrentFrame().damageBox` 采样受击盒 → 世界 AABB）；临时攻击盒；相交检测。
- **前提**：阶段 1（HP 就绪）+ 阶段 0（aabb/collision 包）。
- **验证**：Log 打出"玩家攻击盒 vs 怪物受击盒：命中/未命中"。

## 1. 做什么

### 1.1 LSHitboxComponent（框架包 Model/Share）

```csharp
[ComponentOf(typeof(LSUnit))]
[MemoryPackable]
public partial class LSHitboxComponent : LSEntity, ILSUpdate, IAwake, ISerializeToEntity
{
    // 受击盒（每帧从动画帧的 damageBox 动态采样，这里只缓存当前结果）
    [MemoryPackOrder(0)]
    public AABB CurrentHurtBox;

    // 攻击盒（技能/攻击动作设置）
    [MemoryPackOrder(1)]
    public AABB CurrentAttackBox;
    [MemoryPackOrder(2)]
    public bool AttackEnabled;
}
```

### 1.2 LSHitboxComponentSystem（Hotfix/Share）

每帧 `LSUpdate`：从当前动画帧的 `damageBox` 采样受击盒，加单位位置转世界 AABB：

```csharp
[LSEntitySystem]
private static void LSUpdate(this LSHitboxComponent self)
{
    LSUnit unit = self.GetParent<LSUnit>();
    LSAnimComponent anim = unit.GetComponent<LSAnimComponent>();
    if (anim == null) return;

    AnimFrameData frame = anim.GetCurrentFrame();
    // damageBox 是相对偏移（min/max），加单位世界位置 → 世界 AABB
    TSVector min = unit.Position + new TSVector(frame.damageBox.min.x, frame.damageBox.min.y, frame.damageBox.min.z);
    TSVector max = unit.Position + new TSVector(frame.damageBox.max.x, frame.damageBox.max.y, frame.damageBox.max.z);
    self.CurrentHurtBox = new AABB { Min = min, Max = max };
    // 注意：实际 AABB 结构体字段名以阶段 0 确认的真实 API 为准
}
```

### 1.3 临时攻击盒测试

给玩家加一个临时攻击盒（固定在面前）：

```csharp
// 临时：玩家面前 1 单位处一个 2x2x2 的攻击盒
LSHitboxComponent hitbox = player.GetComponent<LSHitboxComponent>();
hitbox.AttackEnabled = true;
FP facing = player.Forward.x >= FP.Zero ? FP.One : -FP.One;
TSVector center = player.Position + new TSVector(facing * 2, 0, 0);
hitbox.CurrentAttackBox = AABBUtil.FromCenter(center, new TSVector(1, 1, 1));
```

### 1.4 碰撞检测

```csharp
bool hit = AABBUtil.Intersects(attacker.CurrentAttackBox, target.CurrentHurtBox);
Log.Info($"[Hitbox] 攻击 vs 受击：{(hit ? "命中" : "未命中")}");
```

## 3. 注意

> **DNF 坐标系实证定论**（`02-坐标系与包围盒-总结.md`）：
> DNF 坐标：x=横向（右正，规范朝向=面右）；y=纵深；**z=高度（上正，0=地面脚底）**。全像素，与贴图 1:1。
> 我们坐标：TSVector(x=横向, y=高度, z=纵深)，1 单位=100px，Position=脚底中心。
>
> **采样公式（已实证，直接用）**：
> ```csharp
> long s = 100;
> // 先归一化（DNF 有 min/max 倒序脏数据）
> int minX = Math.Min(box.min.x, box.max.x), maxX = Math.Max(box.min.x, box.max.x);
> // ... minY/maxY/minZ/maxZ 同理
> long wx0 = facingRight ? minX : -maxX;   // 面左：x 区间镜像，y/z 不变
> long wx1 = facingRight ? maxX : -minX;
> var worldMin = new TSVector(pos.x + wx0/s, pos.y + minZ/s, pos.z + minY/s);
> var worldMax = new TSVector(pos.x + wx1/s, pos.y + maxZ/s, pos.z + maxY/s);
> ```
> move.json 首帧代入：世界盒 x[-0.16, 0.29]，y[-0.05, 1.06]（角色高约 1.06 单位），z[-0.07, 0.14]。

- **盒几何与命中反应是两层**（DNF 实证）：盒（何时何地判定）在 .ani 帧数据（=我们的 AnimFrameData.damageBox）；命中反应（damageAct/upForce/backForce/hitStunTime）放 attack.json 顶层（每技能一份）。阶段 3.5 细化。
- AABB 的真实字段名/构造方式以阶段 0 确认的为准。
- 受击盒现在是**逻辑层**（每帧采样，确定性），视图层以后画 Gizmo 框。
