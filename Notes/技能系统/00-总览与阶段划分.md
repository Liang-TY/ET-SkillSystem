## 系统目标

在 ET9 帧同步工程里，做一个 DNF/横版格斗风格的技能系统：玩家/怪物有 HP、能攻击、能受击、有 Buff、有投射物、能放技能。所有逻辑确定性（帧同步安全）。

---

## 四层架构（落地后的目标）

```
① lockstep（已有，极小更新）     LSInput 加 Target 字段 + NumericType 常量
② aabb + collision（碰撞基础层）   AABB 结构 + 相交检测 + 宽相遍历
③ skill（技能框架包，新增）        数值组件 / Buff / Cast / Bullet / Area / SkillLogic
④ SkillDefs（技能定义，新增）      每个技能一个类（C# 代码，不是配表）
```

依赖方向：④ → ③ → ② → ①

## 执行原则

1. **顺序执行**：阶段间有依赖（阶段3依赖阶段1的HP+阶段2的碰撞）。
2. **每阶段独立可验证**：完成后能在 Unity 里看到明确效果（Log/可视化/操作）。
3. **代码先于配置**：技能用 C# 写（SkillLogic），不用 Excel 配表。Buff 用 BuffDef 配置驱动。
4. **回滚安全**：所有状态存 LSEntity（`[MemoryPackable]`），SkillLogic 无状态，不用 lambda/delegate。
5. **每阶段文档自带代码参考**：照着写，不需要查阅其他文档。

## 关键决策：视图层 Route B（状态标记 + 轮询 diff）

**不走事件总线**（`EventSystem.Publish`），因为 LSUpdate 在回滚重放时会重复执行，导致事件重复触发（特效乱飞/音效重播/甚至逻辑实体重复创建）。

**Route B 方案**：逻辑实体加状态标记字段（`JustStarted/JustHit/JustFinished/JustAdded/JustRemoved/LastHitstunTimer`），LSUpdate 设标记、下帧清；视图层 IUpdate 轮询标记做 diff 表现。完全确定性、回滚安全。

各阶段实现状态标记的位置：
- 阶段 3.5（打击感）：`LSCombatComponent.LastHitstunTimer`（上帧值，视图 diff 硬直进入/退出）。
- 阶段 4（Cast）：`LSCast.JustStarted/JustHit/JustFinished`。
- 阶段 5（Buff）：`LSBuff.JustAdded/JustRemoved`。
- 阶段 7（视图层）：所有表现基于轮询 diff，不订阅事件。
