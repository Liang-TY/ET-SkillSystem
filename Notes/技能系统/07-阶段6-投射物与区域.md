# 阶段 6：投射物与区域效果

> 弹道（子弹）飞行 + 碰撞命中；区域效果（火圈）持续 Tick。这是"远程技能"和"持续场地"的基础。

---

## 0. 速查

- **目标**：`LSBullet`（弹道实体，飞行 + 碰撞）+ `LSArea`（区域效果，持续 + Enter/Tick/Exit Action）。
- **前提**：阶段 1-5（数值/碰撞/Buff/Actions 都就绪）。
- **验证**：放一个寒冰箭技能 → 子弹飞到怪物位置 → 命中扣血 + 施加眩晕。
- **DNF 研究补充**（`05-复杂技能案例-总结.md`）：弹道三形态（链式生灭/插值平移/一次性攻击对象）；多段间隔命中（定时清空已命中名单）；霸体帧标记（DAMAGE TYPE 三值）。

## 1. 投射物 LSBullet

### 1.1 实体

```csharp
[ChildOf(typeof(LSBulletComponent))]
[MemoryPackable]
public partial class LSBullet : LSEntity, ILSUpdate, IAwake, ISerializeToEntity {
    public TSVector Position;
    public TSVector Direction;
    public FP Speed;
    public FP RemainingTime;
    public long CasterId;
    public int BulletConfigId;
    public LSShapeData Shape;     // 碰撞形状
    // 命中后的 Action（配置驱动，不用 lambda）
    public int[] HitActionIds;
    public HashSet<long> HitTargets;  // 防穿透多重命中
}
```

### 1.2 系统

`LSBullet.LSUpdate`：Position += Direction * Speed * dt；用 Shape 检测碰撞；命中 → 执行 HitActionIds（Damage/AddBuff...）。

### 1.3 创建

`SkillContext.CreateBullet(origin, direction, speed, shape, bulletConfigId)`。

## 2. 区域效果 LSArea

### 2.1 实体

```csharp
[ChildOf(typeof(LSAreaComponent))]
[MemoryPackable]
public partial class LSArea : LSEntity, ILSUpdate, IAwake, ISerializeToEntity {
    public long CasterId;
    public LSShapeData Shape;
    public int RemainingMs;
    public int TickIntervalMs;
    public int TickTimer;
    public int[] EnterActionIds;
    public int[] TickActionIds;
    public int[] ExitActionIds;
    public HashSet<long> AffectedUnits;  // 已进入的单位（防重复 Enter）
}
```

### 2.2 系统

- 单位进入区域（首次相交）→ 执行 EnterActionIds，加入 AffectedUnits。
- 每 TickIntervalMs → 对 AffectedUnits 执行 TickActionIds。
- RemainingMs 到 0 → 对 AffectedUnits 执行 ExitActionIds，销毁。

### 2.3 创建（配置驱动，无 lambda）

```csharp
ctx.CreateArea(shape, durationMs, tickIntervalMs, enterActionIds, tickActionIds, exitActionIds);
```

## 3. 验证

- **寒冰箭**：按技能键 → 子弹从玩家位置朝鼠标方向飞 → 碰到怪物 → 扣血 + 施加 Stun（怪物 1 秒不动）。
- **燃烧区域**：在地上放个火圈 → 怪物走进去 → 每 1 秒扣血 → 走出/区域消失 → 停。

---

## 4. 关键

- 子弹/区域都是 LSEntity，自动参与帧同步快照/回滚。
- 命中效果用 `int[] actionIds` 配置驱动（不用 lambda，回滚安全）。
- LSShapeData 支持圆形/矩形/扇形/环形，判定逻辑在 Contains 方法。

### DNF 研究补充建议（`05 总结` §3）

1. **Bullet 支持两种多段命中模式**：①整轮一次性（现有 HitTargets，攻击结束清空）；②**按间隔反复命中**（HitTargets 定时清空 = DNF `resetHitObjectList` + `setTimeEvent`，穿透/持续弹道用）。
2. **加"一次性攻击对象"概念**：`SkillContext.SpawnOneShotAttack(clip, 攻击信息, 时长)`——瞬时判定体，播完自毁（爆炸帧/落点判定用，DNF `sq_createAttackObjectWithPath` 等价物）。≈ 短命 LSArea 特例。
3. **霸体帧标记**：AnimFrameData 加 `damageType`（0 普通/1 霸体/2 不可打断，DNF `[DAMAGE TYPE]` 三值）；命中检测查霸体（霸体帧只扣血不受击反应）。
