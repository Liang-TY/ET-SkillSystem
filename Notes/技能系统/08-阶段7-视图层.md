## 1. Route B 轮询机制（统一说明）

**不做**：`EventSystem.Publish(CastHit)` + 视图订阅（回滚重放会重复触发）。

**做法**：视图组件（`IUpdate`，Unity 帧跑）每帧读逻辑实体的状态标记/字段，跟上一次缓存的值 diff，变了才表现。

```csharp
// 视图组件 Update 示例
LSCombatComponent combat = unit.GetComponent<LSCombatComponent>();
if (combat == null) return;

// 受击硬直：刚进入硬直（上帧 0、本帧 >0）→ 播受击动画/特效
if (combat.LastHitstunTimer == 0 && combat.HitstunTimer > 0)
{
    PlayHurtAnimation(unit);
    SpawnHitEffect(unit.Position);
}
// 硬直结束（上帧 >0、本帧 0）→ 回 Idle
else if (combat.LastHitstunTimer > 0 && combat.HitstunTimer == 0)
{
    PlayIdleAnimation(unit);
}
```

## 2. 各表现项的轮询源

| 表现 | 轮询什么 | diff 条件 |
|------|---------|----------|
| 技能起手特效 | `LSCast.JustStarted` | true → 播 |
| 命中火花/音效 | `LSCast.JustHit` | true → 播 |
| 技能结束清理 | `LSCast.JustFinished` | true → 清 |
| 受击动画/特效 | `LSCombatComponent.LastHitstunTimer` vs `HitstunTimer` | Last==0 && Cur>0 → 播 |
| 顿帧屏震（可选） | `LSCombatComponent.HitstopTimer` | >0 → 触发屏震 |
| 血条 UI | `LSNumericComponent.Get(Hp)` / `Get(MaxHp)` | 比例变化 → 设 fillAmount |
| 伤害数字 | 上一帧 HP vs 本帧 HP | HP 减 → 飞数字（减多少） |
| Buff 图标出现 | `LSBuff.JustAdded` | true → 创建图标 |
| Buff 图标消失 | `LSBuff.JustRemoved` | true → 销毁图标 |

---

## 3. 血条 UI

- 视图组件读 `numeric.Get(Hp)` / `Get(MaxHp)`，算比例 → 设 `Image.fillAmount`。
- 血条跟随 unit（世界坐标 → 屏幕坐标，或挂在 unit 物体上偏移头顶）。
- 单纯读取，不参与逻辑。

---

## 4. 伤害数字

- 视图组件每帧读 `numeric.Get(Hp)`，跟上一帧缓存比，减了就飞一个伤害数字（差值 = 伤害量）。
- 数字 prefab + Tween（往上飘 + 淡出）。
- 对象池管理。

---

## 5. 特效（prefab）

- 技能起手/命中特效：粒子或序列帧 prefab，YooAsset 加载，对象池。
- 在标记 diff 触发时 `Instantiate`（或从池取），播完 `Recycle`。

---

## 6. 注意

- **标记的时效**：逻辑层标记在 LSUpdate 开头清、末尾设。视图 IUpdate 在 lockstep tick 之间跑（可能一帧 Unity 跑多次逻辑，或多个 Unity 帧跑一次逻辑）。所以视图读到 true 就立刻表现，不要等"下一帧"——因为逻辑层下一个 tick 开头就清了。
- **顿帧期间的视图**：顿帧只冻结逻辑层动画/Cast 推进，视图层的 SpriteRenderer 已经被设到当前帧 sprite 了（顿帧前最后一帧），视觉上是"卡住"——这正是顿帧要的效果。视图层不需要额外处理。
