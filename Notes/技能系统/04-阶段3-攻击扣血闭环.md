# 阶段 3：攻击扣血闭环（最小战斗）

> 玩家按键 → 攻击盒出现 → 碰怪物受击盒 → 怪物扣血。这是"技能系统能用"的第一个里程碑。

---

## 0. 速查

- **目标**：玩家按攻击键（J / 鼠标左键）→ 触发攻击（临时：直接激活攻击盒 + 持续若干帧）→ 碰撞命中 → 怪物 `HP -= damage`。
- **前提**：阶段 1（HP）+ 阶段 2（受击盒/碰撞）。
- **验证**：玩家走近怪物按攻击键 → Console 打 `怪物 HP: 500 → 490 → 480`。

---

## 1. 做什么

### 1.1 输入扩展：攻击键

`LSInput` 加 Button 字段（如果还没有）：

```csharp
// LSInput.Button: 0=无, 1=攻击（帧同步输入要序列化）
```

`LSOperaComponentSystem`（客户端采集输入）：按 J / 鼠标左键 → `input.Button = 1`。

### 1.2 攻击触发逻辑（LSInputComponentSystem 或新建 LSAttackComponent）

最简版：在 `LSInputComponentSystem.LSUpdate` 里检测 Button：

```csharp
if (self.LSInput.Button == 1)
{
    // 临时：直接激活攻击盒，持续几帧
    LSHitboxComponent hitbox = unit.GetComponent<LSHitboxComponent>();
    if (hitbox != null)
    {
        hitbox.AttackEnabled = true;
        FP facing = unit.Forward.x >= FP.Zero ? FP.One : -FP.One;
        TSVector center = unit.Position + new TSVector(facing * 2, 0, 0);
        hitbox.CurrentAttackBox = AABBUtil.FromCenter(center, new TSVector(1,1,1));
    }
}
else
{
    var hitbox = unit.GetComponent<LSHitboxComponent>();
    if (hitbox != null) hitbox.AttackEnabled = false;
}
```

> 这版是"按住就持续攻击"，没有动作动画、没有冷却。阶段 4 用 LSCast/SkillLogic 替换。

### 1.3 命中扣血（LSHitboxComponentSystem.LSUpdate 或单独检测系统）

加一个检测：玩家攻击盒 vs 所有怪物受击盒：

```csharp
// 在某个系统的 LSUpdate 里（或 LSHitboxComponentSystem）
if (self.AttackEnabled)
{
    LSUnit attacker = self.GetParent<LSUnit>();
    LSUnitComponent uc = attacker.LSWorld().GetComponent<LSUnitComponent>();
    foreach (LSUnit target in uc.Children.Values)
    {
        if (target.Id == attacker.Id) continue;
        LSHitboxComponent targetHit = target.GetComponent<LSHitboxComponent>();
        if (targetHit == null) continue;
        if (AABBUtil.Intersects(self.CurrentAttackBox, targetHit.CurrentHurtBox))
        {
            // 命中！扣血
            var targetNum = target.GetComponent<LSNumericComponent>();
            FP damage = FP.FromRaw(50);   // 临时固定伤害
            targetNum.Add(NumericType.Hp, -damage);
            Log.Info($"[Combat] {attacker.Id} 命中 {target.Id}，HP={targetNum.Get(NumericType.Hp)}");
            // ⚠️ 注意防多重命中：一次攻击同一目标只扣一次
            // 临时方案：攻击盒持续期间记录已命中目标 ID，松开按键时清空
        }
    }
}
```

### 1.4 防多重命中（重要！）

攻击盒持续激活期间，每帧都会检测碰撞。如果不处理，按住攻击键每帧都扣血（50ms 一次 = 秒扣 20 次）。

临时方案：`LSHitboxComponent` 加一个 `HashSet<long> HitTargets`（本次攻击已命中目标）。命中后加入集合，按键松开/攻击结束时清空。

---

## 2. 验证

1. 玩家走近怪物，按住 J（或鼠标左键）。
2. Console 打：`[Combat] 玩家 命中 怪物，HP=450`（每次攻击只扣一次）。
3. 松开再按 → 再扣一次。
4. 怪物 HP 到 0 不处理死亡（阶段后续做）。

---

## 3. 注意

- **帧同步确定性**：伤害用 `FP`（定点数），不能用 float。`FP.FromRaw(50)` 或 `(FP)50`。
- **不要每帧扣血**：用 HitTargets 防重。
- **这阶段先不接攻击动画**：攻击盒是"凭空出现"的，没有攻击动作的帧驱动。阶段 4 接 LSCast 后，攻击盒由 SkillLogic 在判定帧激活。

**实现修正记录**：
1. **阶段1遗留bug修复（LSNumericComponentSystem）**：原 `Set` 用 `key % 10 != 0 → UpdateFinal(key/10*10)`，把 HpBase=10011 算到孤儿 key 10010，`Get(Hp=1001)` 恒返 0（五层映射从未生效，阶段1验证行当时未确认）。修正为：`key >= 10000 → UpdateFinal(key/10)`（10011→1001），`UpdateFinal` 读 `finalKey*10+1~5`；**final key 直接写不重算**——当前 HP 扣减/ForbidMove 走直写路径（"当前HP直扣、MaxHp走五层"的正确语义）。
2. **文档笔误**：`FP.FromRaw(50)` 是设内部原始值（≈1.16e-8），不是 50.0；正确写法 `FP damage = 50`（int 隐式转 FP 精确）。
3. 攻击触发放 ForbidMove 检查之前（ForbidMove 只挡移动；挡施法以后用 ForbidSkill）。
4. 组件执行顺序（Id 序）：Input(激活) → Anim(推进帧) → Hitbox(采样+检测+扣血)——按下当帧即命中，无延迟。
5. LSUnitFactory 移除阶段2的 `SetAttackEnabled(true)` 常开；`SetAttackEnabled` 方法删除，换成 `SetAttackInput(bool)` 状态机。
